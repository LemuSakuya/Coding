# 机器学习项目实践

这些项目用于把分章笔记中的公式和代码落到可运行实验。

## 建议项目

1. `01_tabular_baseline`：表格分类 baseline，练习数据切分、Pipeline、指标报告。
2. `02_linear_regression_from_scratch`：从零实现线性回归，比较闭式解和梯度下降。
3. `03_logistic_regression_from_scratch`：从零实现逻辑回归，观察交叉熵下降。
4. `04_text_naive_bayes`：使用词袋模型和朴素贝叶斯完成文本分类。
5. `05_tree_ensemble`：比较决策树、随机森林和梯度提升。
6. `06_unsupervised_lab`：用 KMeans、PCA、GMM 做聚类与可视化。
7. `07_model_selection_lab`：用交叉验证、学习曲线和网格搜索调参。
8. `08_mlops_mini_pipeline`：训练、保存、加载、监控一个简单模型。

## 每个项目的最低要求

- 有固定随机种子。
- 有训练集、验证集、测试集或交叉验证。
- 有至少一个 baseline。
- 有指标报告和错误样本分析。
- 有实验结论，不只保存代码。
