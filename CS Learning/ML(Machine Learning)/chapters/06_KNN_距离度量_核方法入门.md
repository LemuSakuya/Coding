## 06.01 实例学习

### 学习目标

1. 能用自己的话解释“实例学习”解决什么问题。
2. 能写出本节最核心的数学表达式，并知道每个符号的含义。
3. 能把公式翻译成 NumPy 或 Scikit-learn 代码。
4. 能判断本节方法在什么数据条件下会失效。

### 核心概念

- 实例学习不是孤立技巧，而是数据、假设、目标函数和优化过程共同作用的结果。
- 学习时先问输入是什么、输出是什么、模型假设是什么、评价指标是什么。
- 如果模型假设与数据生成机制差距过大，即使优化过程正确，泛化效果也可能很差。
- 如果数据预处理方式错误，后续再复杂的模型也会把错误放大。
- 机器学习的关键习惯是把每个结论落到可观测实验，而不是只记名称。
- 本节涉及的变量都默认按矩阵形式组织，这样便于向量化实现。
- 向量化不仅让代码更快，也让推导更贴近线性代数表达。
- 训练误差下降不等于模型可用，必须同时观察验证集或交叉验证结果。
- 当模型表现异常时，优先检查数据切分、标签、尺度、缺失值和随机种子。
- 真正掌握一个算法，至少要能说清目标函数、优化变量、更新规则和适用边界。

### 数学符号

- $X\in\mathbb{R}^{n\times d}$：包含 $n$ 个样本、$d$ 个特征的设计矩阵。
- $x_i\in\mathbb{R}^{d}$：第 $i$ 个样本的特征向量。
- $y_i$：第 $i$ 个样本的监督信号，可能是类别、实数或排序反馈。
- $\theta$：模型中需要学习的参数集合。
- $\ell(\hat{y}_i,y_i)$：单个样本上的损失函数。
- $J(\theta)$：所有样本损失与正则项组成的优化目标。
- $\eta$：学习率，控制每次参数更新的步长。
- $d_2(x,z)=\sqrt{\sum_j(x_j-z_j)^2}$；$K(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$；$\hat{y}=\operatorname{mode}\{y_i:i\in N_k(x)\}$。

### 推导 1：从预测函数到经验风险

1. 设模型对样本 $x_i$ 的预测为 $\hat{y}_i=f(x_i;\theta)$。
2. 用损失函数度量预测与真实值的差异：$\ell_i=\ell(\hat{y}_i,y_i)$。
3. 训练集上共有 $n$ 个样本，因此平均损失写作：

$$
\mathcal{R}_{emp}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f(x_i;\theta),y_i)
$$

4. 如果加入正则项 $\Omega(\theta)$，目标函数变为：

$$
J(\theta)=\mathcal{R}_{emp}(\theta)+\lambda\Omega(\theta)
$$

5. 实例学习中的建模选择，本质上是在改变 $f$、$\ell$ 或 $\Omega$ 的具体形式。
6. 当 $\lambda=0$ 时，模型只关心训练误差，可能更容易过拟合。
7. 当 $\lambda$ 太大时，模型过度偏向简单参数，可能欠拟合。
8. 因此学习过程需要在拟合能力和复杂度约束之间取平衡。

### 推导 2：梯度下降的一般形式

1. 对目标函数 $J(\theta)$ 求导，得到当前位置最陡上升方向 $\nabla_\theta J(\theta)$。
2. 为了让损失下降，参数沿负梯度方向移动：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t)
$$

3. 若 $\eta$ 太小，收敛缓慢；若 $\eta$ 太大，损失可能震荡或发散。
4. 批量梯度下降使用全部样本估计梯度，稳定但每步较慢。
5. 随机梯度下降使用单个或小批量样本估计梯度，噪声更大但更新更频繁。
6. 小批量梯度下降是深度学习和大规模机器学习中最常见的折中。
7. 如果目标函数是凸函数，合适学习率下可收敛到全局最优或其附近。
8. 如果目标函数非凸，训练结果还会受到初始化、批量顺序和优化器影响。

### 推导 3：矩阵形式的好处

1. 单样本计算清晰，但循环写法容易慢，也容易隐藏维度错误。
2. 把样本堆叠成矩阵后，预测可统一写成 $\hat{y}=f(X;\theta)$。
3. 对线性部分，常见形式是 $z=Xw+b\mathbf{1}$。
4. 对损失函数，常见形式是所有样本损失取均值。
5. 对梯度，常见形式会出现 $X^T$，因为每个特征都要累加所有样本的误差信号。
6. 维度检查是推导中的保险：$X^T e$ 的形状是 $d\times1$，正好对应 $w$。
7. 代码实现时，优先让数组形状与公式保持一致。
8. 如果广播规则让代码“刚好能跑”，也要检查它是否真的表达了公式。

### 代码实现：本节最小实验

```python
import numpy as np

def topic_1_4_standardize(X_train, X_test):
    X_train = np.asarray(X_train, dtype=float)
    X_test = np.asarray(X_test, dtype=float)
    mu = X_train.mean(axis=0)
    sigma = X_train.std(axis=0) + 1e-12
    return (X_train - mu) / sigma, (X_test - mu) / sigma

def topic_1_4_mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.mean((y_true - y_pred) ** 2)

def topic_1_4_train_linear_baseline(X, y, lr=0.05, epochs=300):
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    history = []
    for step in range(epochs):
        pred = X @ w + b
        err = pred - y
        loss = 0.5 * np.mean(err ** 2)
        grad_w = X.T @ err / n
        grad_b = np.mean(err)
        w -= lr * grad_w
        b -= lr * grad_b
        if step % 20 == 0:
            history.append(float(loss))
    return w, b, history

# 运行建议：把本节函数接入真实数据，再比较训练集和验证集误差。
```

### 实验检查点

- 检查输入矩阵是否存在缺失值、无穷值或明显异常量纲。
- 检查训练集和验证集是否使用同一个随机种子可复现切分。
- 检查只在训练集拟合标准化参数，再应用到验证集和测试集。
- 检查损失曲线是否整体下降，而不是一开始就发散。
- 检查模型在训练集和验证集上的差距，判断是否过拟合。
- 检查预测结果的分布是否符合任务常识。
- 检查指标是否和业务目标一致，例如排序任务不要只看准确率。
- 检查是否记录了数据版本、代码版本、参数和随机种子。

### 常见错误

1. 把测试集参与特征选择、标准化拟合或调参，造成数据泄漏。
2. 只报告最好的单次结果，不报告随机种子和方差。
3. 没有确认标签含义，导致把反向标签当成正向标签。
4. 忽略类别不平衡，在极端数据上被准确率误导。
5. 不看残差、不看混淆矩阵、不看错误样本，只盯一个总分。
6. 公式会背，但写代码时没有做维度检查。
7. 训练集表现很好就停止分析，没有解释泛化能力。
8. 不保存实验配置，导致结果无法复现。

### 小结

实例学习这一节要把概念、公式、代码和实验四件事连起来。
如果只能记住一个原则，就是任何模型选择都要回到数据假设和评价目标。
当你能从目标函数推到梯度，再从梯度写出更新代码，本节就算真正过关。

- $\ell(\hat{y}_i,y_i)$：单个样本上的损失函数。
- $J(\theta)$：所有样本损失与正则项组成的优化目标。
- $\eta$：学习率，控制每次参数更新的步长。
- $d_2(x,z)=\sqrt{\sum_j(x_j-z_j)^2}$；$K(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$；$\hat{y}=\operatorname{mode}\{y_i:i\in N_k(x)\}$。

### 推导 1：从预测函数到经验风险

1. 设模型对样本 $x_i$ 的预测为 $\hat{y}_i=f(x_i;\theta)$。
2. 用损失函数度量预测与真实值的差异：$\ell_i=\ell(\hat{y}_i,y_i)$。
3. 训练集上共有 $n$ 个样本，因此平均损失写作：

$$
\mathcal{R}_{emp}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f(x_i;\theta),y_i)
$$

4. 如果加入正则项 $\Omega(\theta)$，目标函数变为：

$$
J(\theta)=\mathcal{R}_{emp}(\theta)+\lambda\Omega(\theta)
$$

5. 曼哈顿距离中的建模选择，本质上是在改变 $f$、$\ell$ 或 $\Omega$ 的具体形式。
6. 当 $\lambda=0$ 时，模型只关心训练误差，可能更容易过拟合。
7. 当 $\lambda$ 太大时，模型过度偏向简单参数，可能欠拟合。
8. 因此学习过程需要在拟合能力和复杂度约束之间取平衡。

### 推导 2：梯度下降的一般形式

1. 对目标函数 $J(\theta)$ 求导，得到当前位置最陡上升方向 $\nabla_\theta J(\theta)$。
2. 为了让损失下降，参数沿负梯度方向移动：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t)
$$

3. 若 $\eta$ 太小，收敛缓慢；若 $\eta$ 太大，损失可能震荡或发散。
4. 批量梯度下降使用全部样本估计梯度，稳定但每步较慢。
5. 随机梯度下降使用单个或小批量样本估计梯度，噪声更大但更新更频繁。
6. 小批量梯度下降是深度学习和大规模机器学习中最常见的折中。
7. 如果目标函数是凸函数，合适学习率下可收敛到全局最优或其附近。
8. 如果目标函数非凸，训练结果还会受到初始化、批量顺序和优化器影响。

### 推导 3：矩阵形式的好处

1. 单样本计算清晰，但循环写法容易慢，也容易隐藏维度错误。
2. 把样本堆叠成矩阵后，预测可统一写成 $\hat{y}=f(X;\theta)$。
3. 对线性部分，常见形式是 $z=Xw+b\mathbf{1}$。
4. 对损失函数，常见形式是所有样本损失取均值。
5. 对梯度，常见形式会出现 $X^T$，因为每个特征都要累加所有样本的误差信号。
6. 维度检查是推导中的保险：$X^T e$ 的形状是 $d\times1$，正好对应 $w$。
7. 代码实现时，优先让数组形状与公式保持一致。
8. 如果广播规则让代码“刚好能跑”，也要检查它是否真的表达了公式。

### 代码实现：本节最小实验

```python
import numpy as np

def topic_3_5_standardize(X_train, X_test):
    X_train = np.asarray(X_train, dtype=float)
    X_test = np.asarray(X_test, dtype=float)
    mu = X_train.mean(axis=0)
    sigma = X_train.std(axis=0) + 1e-12
    return (X_train - mu) / sigma, (X_test - mu) / sigma

def topic_3_5_mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.mean((y_true - y_pred) ** 2)

def topic_3_5_train_linear_baseline(X, y, lr=0.05, epochs=300):
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    history = []
    for step in range(epochs):
        pred = X @ w + b
        err = pred - y
        loss = 0.5 * np.mean(err ** 2)
        grad_w = X.T @ err / n
        grad_b = np.mean(err)
        w -= lr * grad_w
        b -= lr * grad_b
        if step % 20 == 0:
            history.append(float(loss))
    return w, b, history

```

- 检查训练集和验证集是否使用同一个随机种子可复现切分。
- 检查只在训练集拟合标准化参数，再应用到验证集和测试集。
- 检查损失曲线是否整体下降，而不是一开始就发散。
- 检查模型在训练集和验证集上的差距，判断是否过拟合。
- 检查预测结果的分布是否符合任务常识。
- 检查指标是否和业务目标一致，例如排序任务不要只看准确率。
- 检查是否记录了数据版本、代码版本、参数和随机种子。

### 常见错误

1. 把测试集参与特征选择、标准化拟合或调参，造成数据泄漏。
2. 只报告最好的单次结果，不报告随机种子和方差。
3. 没有确认标签含义，导致把反向标签当成正向标签。
4. 忽略类别不平衡，在极端数据上被准确率误导。

## 06.06 加权 KNN

### 学习目标

1. 能用自己的话解释“加权 KNN”解决什么问题。
2. 能写出本节最核心的数学表达式，并知道每个符号的含义。
3. 能把公式翻译成 NumPy 或 Scikit-learn 代码。
4. 能判断本节方法在什么数据条件下会失效。

### 核心概念

- 加权 KNN不是孤立技巧，而是数据、假设、目标函数和优化过程共同作用的结果。
- 学习时先问输入是什么、输出是什么、模型假设是什么、评价指标是什么。
- 如果模型假设与数据生成机制差距过大，即使优化过程正确，泛化效果也可能很差。
- 如果数据预处理方式错误，后续再复杂的模型也会把错误放大。
- 机器学习的关键习惯是把每个结论落到可观测实验，而不是只记名称。
- 本节涉及的变量都默认按矩阵形式组织，这样便于向量化实现。
- 向量化不仅让代码更快，也让推导更贴近线性代数表达。
- 训练误差下降不等于模型可用，必须同时观察验证集或交叉验证结果。
- 当模型表现异常时，优先检查数据切分、标签、尺度、缺失值和随机种子。
- 真正掌握一个算法，至少要能说清目标函数、优化变量、更新规则和适用边界。

### 数学符号

- $X\in\mathbb{R}^{n\times d}$：包含 $n$ 个样本、$d$ 个特征的设计矩阵。
- $x_i\in\mathbb{R}^{d}$：第 $i$ 个样本的特征向量。
- $y_i$：第 $i$ 个样本的监督信号，可能是类别、实数或排序反馈。
- $\theta$：模型中需要学习的参数集合。
- $\ell(\hat{y}_i,y_i)$：单个样本上的损失函数。
- $J(\theta)$：所有样本损失与正则项组成的优化目标。
- $\eta$：学习率，控制每次参数更新的步长。
- $d_2(x,z)=\sqrt{\sum_j(x_j-z_j)^2}$；$K(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$；$\hat{y}=\operatorname{mode}\{y_i:i\in N_k(x)\}$。

### 推导 1：从预测函数到经验风险

1. 设模型对样本 $x_i$ 的预测为 $\hat{y}_i=f(x_i;\theta)$。
2. 用损失函数度量预测与真实值的差异：$\ell_i=\ell(\hat{y}_i,y_i)$。
3. 训练集上共有 $n$ 个样本，因此平均损失写作：

$$
\mathcal{R}_{emp}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f(x_i;\theta),y_i)
$$

4. 如果加入正则项 $\Omega(\theta)$，目标函数变为：

$$
J(\theta)=\mathcal{R}_{emp}(\theta)+\lambda\Omega(\theta)
$$

5. 加权 KNN中的建模选择，本质上是在改变 $f$、$\ell$ 或 $\Omega$ 的具体形式。
6. 当 $\lambda=0$ 时，模型只关心训练误差，可能更容易过拟合。
7. 当 $\lambda$ 太大时，模型过度偏向简单参数，可能欠拟合。
8. 因此学习过程需要在拟合能力和复杂度约束之间取平衡。

### 推导 2：梯度下降的一般形式

1. 对目标函数 $J(\theta)$ 求导，得到当前位置最陡上升方向 $\nabla_\theta J(\theta)$。
2. 为了让损失下降，参数沿负梯度方向移动：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t)
$$

3. 若 $\eta$ 太小，收敛缓慢；若 $\eta$ 太大，损失可能震荡或发散。
4. 批量梯度下降使用全部样本估计梯度，稳定但每步较慢。
5. 随机梯度下降使用单个或小批量样本估计梯度，噪声更大但更新更频繁。
6. 小批量梯度下降是深度学习和大规模机器学习中最常见的折中。
7. 如果目标函数是凸函数，合适学习率下可收敛到全局最优或其附近。
8. 如果目标函数非凸，训练结果还会受到初始化、批量顺序和优化器影响。

### 推导 3：矩阵形式的好处

1. 单样本计算清晰，但循环写法容易慢，也容易隐藏维度错误。
2. 把样本堆叠成矩阵后，预测可统一写成 $\hat{y}=f(X;\theta)$。
3. 对线性部分，常见形式是 $z=Xw+b\mathbf{1}$。
4. 对损失函数，常见形式是所有样本损失取均值。
5. 对梯度，常见形式会出现 $X^T$，因为每个特征都要累加所有样本的误差信号。
6. 维度检查是推导中的保险：$X^T e$ 的形状是 $d\times1$，正好对应 $w$。
7. 代码实现时，优先让数组形状与公式保持一致。
8. 如果广播规则让代码“刚好能跑”，也要检查它是否真的表达了公式。

- 本节涉及的变量都默认按矩阵形式组织，这样便于向量化实现。
- 向量化不仅让代码更快，也让推导更贴近线性代数表达。
- 训练误差下降不等于模型可用，必须同时观察验证集或交叉验证结果。
- 当模型表现异常时，优先检查数据切分、标签、尺度、缺失值和随机种子。
- 真正掌握一个算法，至少要能说清目标函数、优化变量、更新规则和适用边界。

### 数学符号

- $X\in\mathbb{R}^{n\times d}$：包含 $n$ 个样本、$d$ 个特征的设计矩阵。
- $x_i\in\mathbb{R}^{d}$：第 $i$ 个样本的特征向量。
- $y_i$：第 $i$ 个样本的监督信号，可能是类别、实数或排序反馈。
- $\theta$：模型中需要学习的参数集合。
- $\ell(\hat{y}_i,y_i)$：单个样本上的损失函数。
- $J(\theta)$：所有样本损失与正则项组成的优化目标。
- $\eta$：学习率，控制每次参数更新的步长。
- $d_2(x,z)=\sqrt{\sum_j(x_j-z_j)^2}$；$K(x,z)=\exp(-\gamma\lVert x-z\rVert^2)$；$\hat{y}=\operatorname{mode}\{y_i:i\in N_k(x)\}$。

### 推导 1：从预测函数到经验风险

1. 设模型对样本 $x_i$ 的预测为 $\hat{y}_i=f(x_i;\theta)$。
2. 用损失函数度量预测与真实值的差异：$\ell_i=\ell(\hat{y}_i,y_i)$。
3. 训练集上共有 $n$ 个样本，因此平均损失写作：

$$
\mathcal{R}_{emp}(\theta)=\frac{1}{n}\sum_{i=1}^{n}\ell(f(x_i;\theta),y_i)
$$

4. 如果加入正则项 $\Omega(\theta)$，目标函数变为：

$$
J(\theta)=\mathcal{R}_{emp}(\theta)+\lambda\Omega(\theta)
$$

5. 核函数直觉中的建模选择，本质上是在改变 $f$、$\ell$ 或 $\Omega$ 的具体形式。
6. 当 $\lambda=0$ 时，模型只关心训练误差，可能更容易过拟合。
7. 当 $\lambda$ 太大时，模型过度偏向简单参数，可能欠拟合。
8. 因此学习过程需要在拟合能力和复杂度约束之间取平衡。

### 推导 2：梯度下降的一般形式

1. 对目标函数 $J(\theta)$ 求导，得到当前位置最陡上升方向 $\nabla_\theta J(\theta)$。
2. 为了让损失下降，参数沿负梯度方向移动：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta J(\theta_t)
$$

3. 若 $\eta$ 太小，收敛缓慢；若 $\eta$ 太大，损失可能震荡或发散。
4. 批量梯度下降使用全部样本估计梯度，稳定但每步较慢。
5. 随机梯度下降使用单个或小批量样本估计梯度，噪声更大但更新更频繁。
6. 小批量梯度下降是深度学习和大规模机器学习中最常见的折中。
7. 如果目标函数是凸函数，合适学习率下可收敛到全局最优或其附近。
8. 如果目标函数非凸，训练结果还会受到初始化、批量顺序和优化器影响。

### 推导 3：矩阵形式的好处

1. 单样本计算清晰，但循环写法容易慢，也容易隐藏维度错误。
2. 把样本堆叠成矩阵后，预测可统一写成 $\hat{y}=f(X;\theta)$。
3. 对线性部分，常见形式是 $z=Xw+b\mathbf{1}$。
4. 对损失函数，常见形式是所有样本损失取均值。
5. 对梯度，常见形式会出现 $X^T$，因为每个特征都要累加所有样本的误差信号。
6. 维度检查是推导中的保险：$X^T e$ 的形状是 $d\times1$，正好对应 $w$。
7. 代码实现时，优先让数组形状与公式保持一致。
8. 如果广播规则让代码“刚好能跑”，也要检查它是否真的表达了公式。

### 代码实现：本节最小实验

```python
import numpy as np

def topic_8_5_standardize(X_train, X_test):
    X_train = np.asarray(X_train, dtype=float)
    X_test = np.asarray(X_test, dtype=float)
    mu = X_train.mean(axis=0)
    sigma = X_train.std(axis=0) + 1e-12
    return (X_train - mu) / sigma, (X_test - mu) / sigma

def topic_8_5_mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.mean((y_true - y_pred) ** 2)

def topic_8_5_train_linear_baseline(X, y, lr=0.05, epochs=300):
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    history = []
    for step in range(epochs):
        pred = X @ w + b
        err = pred - y
        loss = 0.5 * np.mean(err ** 2)
        grad_w = X.T @ err / n
        grad_b = np.mean(err)
        w -= lr * grad_w
        b -= lr * grad_b
        if step % 20 == 0:
            history.append(float(loss))
    return w, b, history

```

### 实验检查点

- 检查输入矩阵是否存在缺失值、无穷值或明显异常量纲。
- 检查训练集和验证集是否使用同一个随机种子可复现切分。
- 检查只在训练集拟合标准化参数，再应用到验证集和测试集。
- 检查损失曲线是否整体下降，而不是一开始就发散。
- 检查模型在训练集和验证集上的差距，判断是否过拟合。
- 检查预测结果的分布是否符合任务常识。
- 检查指标是否和业务目标一致，例如排序任务不要只看准确率。
- 检查是否记录了数据版本、代码版本、参数和随机种子。

### 常见错误

1. 把测试集参与特征选择、标准化拟合或调参，造成数据泄漏。
2. 只报告最好的单次结果，不报告随机种子和方差。
3. 没有确认标签含义，导致把反向标签当成正向标签。
4. 忽略类别不平衡，在极端数据上被准确率误导。
5. 不看残差、不看混淆矩阵、不看错误样本，只盯一个总分。
6. 公式会背，但写代码时没有做维度检查。

8. 不保存实验配置，导致结果无法复现。

### 小结

核函数直觉这一节要把概念、公式、代码和实验四件事连起来。

2. 把样本堆叠成矩阵后，预测可统一写成 $\hat{y}=f(X;\theta)$。
3. 对线性部分，常见形式是 $z=Xw+b\mathbf{1}$。
4. 对损失函数，常见形式是所有样本损失取均值。
5. 对梯度，常见形式会出现 $X^T$，因为每个特征都要累加所有样本的误差信号。
6. 维度检查是推导中的保险：$X^T e$ 的形状是 $d\times1$，正好对应 $w$。
7. 代码实现时，优先让数组形状与公式保持一致。
8. 如果广播规则让代码“刚好能跑”，也要检查它是否真的表达了公式。

```python
import numpy as np

def topic_10_6_standardize(X_train, X_test):
    X_train = np.asarray(X_train, dtype=float)
    X_test = np.asarray(X_test, dtype=float)
    mu = X_train.mean(axis=0)
    sigma = X_train.std(axis=0) + 1e-12
    return (X_train - mu) / sigma, (X_test - mu) / sigma

def topic_10_6_mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    return np.mean((y_true - y_pred) ** 2)

def topic_10_6_train_linear_baseline(X, y, lr=0.05, epochs=300):
    X = np.asarray(X, dtype=float)
    y = np.asarray(y, dtype=float)
    n, d = X.shape
    w = np.zeros(d)
    b = 0.0
    history = []
    for step in range(epochs):
        pred = X @ w + b
        err = pred - y
        loss = 0.5 * np.mean(err ** 2)
        grad_w = X.T @ err / n
        grad_b = np.mean(err)
        w -= lr * grad_w
        b -= lr * grad_b
        if step % 20 == 0:
            history.append(float(loss))
    return w, b, history

# 运行建议：把本节函数接入真实数据，再比较训练集和验证集误差。
```

### 实验检查点

- 检查输入矩阵是否存在缺失值、无穷值或明显异常量纲。
- 检查训练集和验证集是否使用同一个随机种子可复现切分。
- 检查只在训练集拟合标准化参数，再应用到验证集和测试集。
- 检查损失曲线是否整体下降，而不是一开始就发散。
- 检查模型在训练集和验证集上的差距，判断是否过拟合。
- 检查预测结果的分布是否符合任务常识。
- 检查指标是否和业务目标一致，例如排序任务不要只看准确率。
- 检查是否记录了数据版本、代码版本、参数和随机种子。

### 常见错误

1. 把测试集参与特征选择、标准化拟合或调参，造成数据泄漏。
2. 只报告最好的单次结果，不报告随机种子和方差。
3. 没有确认标签含义，导致把反向标签当成正向标签。
4. 忽略类别不平衡，在极端数据上被准确率误导。
5. 不看残差、不看混淆矩阵、不看错误样本，只盯一个总分。
6. 公式会背，但写代码时没有做维度检查。
7. 训练集表现很好就停止分析，没有解释泛化能力。
8. 不保存实验配置，导致结果无法复现。

### 小结

高维距离问题这一节要把概念、公式、代码和实验四件事连起来。
如果只能记住一个原则，就是任何模型选择都要回到数据假设和评价目标。
当你能从目标函数推到梯度，再从梯度写出更新代码，本节就算真正过关。

## 本章完整代码实现

- KNN 的训练成本低，但预测时要计算距离，因此工程上常需要索引结构或近似搜索。
- 特征缩放对 KNN 极其重要，因为距离会被量纲大的特征支配。

```python
import numpy as np
from collections import Counter

class KNNClassifier:
    def __init__(self, k=5):
        self.k = k

    def fit(self, X, y):
        self.X_train = np.asarray(X, dtype=float)
        self.y_train = np.asarray(y)
        return self

    def _distances(self, x):
        diff = self.X_train - x
        return np.sqrt(np.sum(diff * diff, axis=1))

    def predict_one(self, x):
        dist = self._distances(x)
        idx = np.argsort(dist)[:self.k]
        votes = Counter(self.y_train[idx])
        return votes.most_common(1)[0][0]

    def predict(self, X):
        return np.array([self.predict_one(x) for x in np.asarray(X, dtype=float)])

def rbf_kernel(X, Z, gamma=1.0):
    X2 = np.sum(X * X, axis=1, keepdims=True)
    Z2 = np.sum(Z * Z, axis=1, keepdims=True).T
    dist2 = X2 + Z2 - 2 * X @ Z.T
    return np.exp(-gamma * dist2)
```
