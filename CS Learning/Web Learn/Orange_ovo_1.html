生存指南：数字时代的自我关怀

基于我们的研究，我们为你整理了这份指南

  • • 打造治愈内容库：关注那些能给你带来温暖和力量的账号
  • • 寻找同温层支持：加入积极的互助小组，找到能理解你的人
  • • 利用匿名宣泄：在安全的平台释放你的情绪，不要压抑自己
  • • 数字断舍离：定期清理你的关注列表，取关那些让你焦虑的内容
  • • 关闭算法茧房：主动打破信息闭环，不要只看同类内容
  • • 远离触发内容：看到自残、自杀相关内容时，立刻划走并举报
  • • 保护隐私：不要在网络上过度暴露你的敏感信息
  • • 尝试线上转线下：当你在网上认识了值得信任的朋友，试着见面聊聊
  • • 学会说不：对于那些消耗你的关系，勇敢地拒绝
  • • 永远不要拒绝专业帮助：网络支持不能替代医生和心理咨询师
  • • 遵医嘱服药：不要因为网上的谣言就擅自停药
  • • 危机时刻请拨打援助热线：你值得被拯救
