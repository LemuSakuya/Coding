🚀 路线 · STEP BY STEP

如何开始刷题？

1

第一阶段：Python 基础语法（2~3 周）

变量、循环、函数、列表、字典。在 Educoder 或 菜鸟教程 上练习。不需要学得很深，能看懂基本代码即可。

2

第二阶段：简单题 100 道（4~6 周）

按「数组 → 字符串 → 哈希表 → 链表 → 栈」顺序刷。每天 1~2 题，先自己想 10 分钟，不会再看题解。重点：理解思路 > 抄代码。

3

第三阶段：专题突破（4~8 周）

二分查找、双指针、滑动窗口、递归/回溯、动态规划入门。每个专题先看视频理解原理，再集中刷 10~20 题巩固。

4

第四阶段：竞赛实战（持续）

参加 蓝桥杯（适合新手）、ACM 校赛（进阶）、LeetCode 周赛。比赛是最好的检验方式，也能认识志同道合的同学。

🔥 核心原则：每天 1~2 题，坚持比数量更重要。100 天后回头看，你会惊讶自己的成长。
📌 避坑：不要一上来就刷 Hard 题，不要只看不写，不要死磕一道题超过 30 分钟。

💻 实战 · LIVE DEMO

LeetCode 实战：Two Sum

📌 题目：两数之和 (LeetCode #1)

给定一个整数数组 nums 和一个目标值 target，找出数组中和为目标值的两个数的下标。

输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]（因为 nums[0] + nums[1] = 9）

💡 解法：哈希表，O(n)
遍历数组，用字典存储「值 → 下标」。对于每个数，检查 target - num 是否已在字典中。 
# Two Sum — 哈希表 O(n) 解法
def twoSum(nums, target):
    dic = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in dic:
            return [dic[complement], i]
        dic[num] = i
    return []

# 测试
nums = [2, 7, 11, 15]
target = 9
print(twoSum(nums, target))  # [0, 1]

4. AI 自动 Debug

⚠️ 重要提醒：AI 不能代替学习。你必须自己理解代码逻辑，AI 是「加速器」不是「代驾」。 先打好基础，再借助 AI 提高效率——顺序不能反。

🤖 工具 · CLAUDE CODE ⭐重点

Claude Code 是什么？

💻

命令行 AI 编程工具

在终端里直接用自然语言让 AI 写代码、改代码。不需要复制粘贴，不需要 IDE 插件。

📂

直接读取整个项目

理解项目结构、文件关系、代码上下文。不是只给一个文件，而是理解整个工程。

⚡

自动生成 & 修改代码

「帮我写一个贪心算法」、「把这个函数改成异步的」——一句话，自动完成。

🔧

自动 Debug

报错了？把错误信息发给 Claude Code，它能定位问题并直接修改代码修复。

🌐

多语言支持

Python · C++ · Java · JavaScript · HTML/CSS · Go · Rust · 机器学习项目，全都能处理。

🔄

Git 友好

AI 帮你写 commit message、review 代码、解决冲突。整个工作流在终端一气呵成。

🐍 Python ⚙️ C++ ☕ Java 🌐 HTML/CSS/JS 🧠 ML/DL
