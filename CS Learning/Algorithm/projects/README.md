# 算法设计与分析 · 项目实践总览

本目录提供 6 个递进式项目，对应 Algorithm 的理论章节。项目不追求大而全，重点是把算法知识变成可运行、可复盘、可复用的工程资产。

---

## 项目列表

| # | 项目 | 对应章节 | 关键技术 |
|---|------|----------|----------|
| 01 | online_judge_template | Ch 01、02、06、07、08、09、10 | 快速 I/O、模板库、最小测试 |
| 02 | shortest_path_visualizer | Ch 07、11 | BFS、Dijkstra、路径恢复、可视化 |
| 03 | dp_problem_set | Ch 08 | 线性 DP、背包、区间、树形、状压 |
| 04 | string_matching_lab | Ch 09 | 暴力、KMP、Trie、Hash、AC 自动机 |
| 05 | random_test_and_stress | Ch 12 | 随机数据、暴力解、对拍、反例保存 |
| 06 | interview_algorithm_pack | Ch 01~12 | 题解表达、复杂度分析、边界用例 |

---

## 通用要求

每个项目至少包含：

1. README：背景、目标、知识点、运行方式、扩展任务。
2. src 或 scripts：核心代码。
3. tests：最小样例或随机测试。
4. notes：遇到的错误和复盘。

---

## 学习建议

1. 先读对应章节，再做项目。
2. 先写最小版本，再逐步扩展。
3. 每个项目都要保留一个“失败样例”。
4. 代码模板要配测试，否则模板不可信。
