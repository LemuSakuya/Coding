# Online Judge 模板库

## 项目目标

建立可复用的竞赛/面试算法模板库。

---

## 对应知识点

- 快速输入输出
- 数组和图初始化
- 常用 typedef 和常量
- 图论、DP、字符串、数学模板
- 每个模板的最小测试

---

## 推荐任务

1. 整理 C++17 和 Python 两套入口模板。
2. 为 Dijkstra、并查集、KMP、背包各写一个最小测试。
3. 记录每个模板的适用条件和复杂度。

---

## 输出要求

- README 中写明算法思想和复杂度。
- 至少提供一个最小可运行样例。
- 至少记录一个边界样例或失败样例。
- 如果包含代码，保证可以从命令行直接运行。
