# 人工神经网络实战项目总览

> 4 个从入门到进阶的实战项目，强调“从零实现 + 框架训练 + 实验记录 + 结果分析”。
> 建议每个项目都保留：数据说明、模型结构、训练日志、可视化结果、失败分析与改进记录。

---

## 实战原则

1. 先做最小可运行版本，再逐步增强。
2. 每个项目至少完成一次“纯 Numpy 版本”或“最简 PyTorch 版本”。
3. 保存训练日志，不要只看最后的准确率。
4. 对每个模型都做一次错误分析：哪些样本错了，为什么错。
5. 至少比较两个配置：基线版与改进版。

## 通用实验记录模板

| 项目 | 内容 |
|------|------|
| 任务目标 | 例如二分类、十分类、序列分类 |
| 数据集 | 数据来源、样本数量、输入形状 |
| 模型结构 | 层数、宽度、激活函数、损失函数 |
| 优化器 | SGD / Adam / 其他 |
| 训练设置 | batch size、学习率、epoch、种子 |
| 结果 | loss、accuracy、F1、混淆矩阵 |
| 问题 | 过拟合、欠拟合、收敛慢、震荡 |
| 改进 | 正则化、数据增强、调参、改结构 |

## 进阶建议

- XOR 项目用来理解非线性与反向传播。
- MNIST 项目用来掌握完整分类流程。
- CIFAR-10 项目用来理解图像任务和卷积结构。
- 序列分类项目用来理解 RNN / LSTM / 注意力。

## 复盘要求

每个项目结束后写一页复盘，至少回答：

1. 我解决了什么问题？
2. 模型为什么能工作？
3. 训练过程中最难的点是什么？
4. 哪个超参数最敏感？
5. 如果重做一次，我会先改哪里？
