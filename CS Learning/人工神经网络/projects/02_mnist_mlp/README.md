## 数据集

MNIST 是 28x28 的灰度手写数字图像，共 10 类：0 到 9。

| 集合 | 数量 |
|------|------|
| 训练集 | 60000 |
| 测试集 | 10000 |

输入通常要做：

- 展平为 784 维向量；
- 转成 float；
- 归一化到 0 到 1 或做标准化。

---

## 建议结构

```text
784 -> 256 -> 128 -> 10
```

- 隐藏层激活：ReLU
- 输出层：Softmax
- 损失函数：CrossEntropyLoss
- 优化器：Adam

- MLP 在 MNIST 上可以获得不错的基线结果，但通常不如 CNN。

## 常见问题

1. 输入没有归一化，训练会慢很多。
2. 标签和输出类别数不一致。
3. 学习率太大导致 loss 不稳定。
4. 只看训练准确率，不看验证准确率。
5. 忘记 flatten 图像，导致维度错误。

## 数据处理细节

MNIST 看起来简单，但很多入门实验失败并不是模型不行，而是数据处理出了问题。你应该在代码里明确完成以下操作。

### 1. 像素归一化

原始像素一般是 0 到 255 的整数。把它们缩放到 0 到 1 可以让训练更稳定。

```python
images = images.float() / 255.0
```

如果你希望更进一步，也可以按训练集统计均值和标准差再做标准化。

### 2. 图像展平

MLP 不直接处理二维空间结构，所以通常需要把 28x28 图像展平为 784 维向量。

```python
images = images.view(images.size(0), -1)
```

这个步骤的意义不是“破坏图像结构”，而是为了先理解最基础的全连接分类器。

### 3. 标签检查

标签应该在 0 到 9 之间，且不要出现字符串形式或 one-hot 误用。

### 4. 数据划分建议

如果你想更认真地做实验，可以从训练集中切出一部分作为验证集，而不是只看测试集。

## 模型设计细节

一个 MNIST MLP 并不需要特别复杂，但你应该理解每一层的职责。

### 输入层

输入层负责接收 784 维向量。它本身没有参数，真正起作用的是后面的线性层。

### 隐藏层

隐藏层是 MLP 学习非线性表示的核心。你可以先从两个隐藏层开始：

- 第一层：784 -> 256
- 第二层：256 -> 128
- 第三层：128 -> 10

如果你想观察模型容量变化，可以尝试更小或更大的配置。

### 激活函数

隐藏层常用 ReLU，因为它简单、收敛快，而且在很多任务上表现稳定。你也可以尝试 Tanh 来比较差异。

### 输出层

输出层给出 10 类 logits。不要在模型里手动写 softmax 再喂给 CrossEntropyLoss，因为很多框架内部已经做了数值稳定处理。

---

## 训练循环拆解

一个完整训练循环应该包含以下步骤。

### 1. 模型进入训练模式

```python
model.train()
```

这一步的意义是让 Dropout、BatchNorm 等层进入训练行为。

### 2. 前向传播

把一个 batch 的输入传入模型，得到输出 logits。

### 3. 计算损失

用交叉熵比较预测和真实标签之间的差距。

### 4. 梯度清零

如果不清零，梯度会在多个 batch 之间累积，导致更新错误。

### 5. 反向传播

```python
loss.backward()
```

这一步计算每个参数对 loss 的梯度。

### 6. 参数更新

```python
optimizer.step()
```

这一步把梯度转成新的参数值。

### 7. 统计指标

记录 loss、accuracy、学习率、时间开销等信息。

## 验证与测试

训练集表现好不代表模型真的好。你必须单独看验证集和测试集。

### 验证集的作用

验证集主要用于：

- 比较不同模型结构；
- 选择超参数；
- 决定是否早停；
- 判断是否过拟合。

### 测试集的作用

测试集只用于最终汇报，不应该反复参与调参。

### 推荐输出

每次验证至少打印：

- 验证 loss
- 验证 accuracy
- 每类召回率
- 最容易混淆的类别对

---

## 错误分析模板

建议每次训练完都做一次错误分析，而不是只写一个准确率数字。

### 可以观察什么

1. 哪些类别最容易被混淆。
2. 错误样本是不是书写风格特别奇怪。
3. 模型是否偏向某些数字。
4. 是否有某些形状的字迹被系统性误判。

### 结果记录示例

| 样本类型 | 现象 | 可能原因 |
|----------|------|----------|
| 4 和 9 | 容易混淆 | 笔画结构接近 |
| 3 和 5 | 偶尔混淆 | 手写风格差异大 |
| 1 和 7 | 少量混淆 | 书写习惯影响 |

---

## 超参数建议

下面是一组适合入门实验的起点，不是唯一答案。

| 超参数 | 建议值 | 说明 |
|--------|--------|------|
| batch size | 64 或 128 | 兼顾稳定与速度 |
| learning rate | 1e-3 或 1e-4 | Adam 常见起点 |
| epochs | 10 到 30 | 先看是否收敛 |
| hidden size | 128 或 256 | 不要一开始太大 |
| dropout | 0.1 到 0.5 | 观察过拟合情况 |

如果训练 loss 降不下去，优先看学习率和数据是否正确；如果训练 loss 很低但验证差，则优先加正则化和数据增强。

## 从基线到改进版

建议你至少做两轮实验。

### 基线版

- 仅用纯 MLP；
- 两个隐藏层；
- ReLU + CrossEntropyLoss + Adam；
- 不加太复杂的技巧。

### 改进版

- 加 Dropout；
- 加 BatchNorm；
- 尝试学习率调度；
- 调整隐藏层宽度和深度；
- 与 CNN 做对比。

### 对比重点

不是只看最终 accuracy，还要看：

- 收敛速度；
- 验证曲线是否稳定；
- 参数量；
- 推理速度；
- 错误类型是否变化。
