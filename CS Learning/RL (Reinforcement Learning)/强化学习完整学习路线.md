### 0.2 学习节奏建议

### 0.3 符号约定（全文统一）

本路线使用 Sutton & Barto 第二版符号，和课件、Silver 课程一致。

- \(S_t, A_t, R_t\)：时刻 \(t\) 的状态、动作、奖励。约定 \(R_{t+1}\) 是执行 \(A_t\) 之后环境给出的奖励。
- \(\mathcal{S}, \mathcal{A}\)：状态空间、动作空间。有限时称表格型（tabular）。
- \(p(s', r \mid s, a) = \Pr(S_{t+1}=s', R_{t+1}=r \mid S_t=s, A_t=a)\)：环境动力学。
- \(\pi(a \mid s)\)：随机策略；\(a = \mu(s)\)：确定性策略。
- \(G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots\)：从 \(t\) 起的折扣回报。
- \(v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]\)：状态价值。
- \(q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]\)：动作价值。
- \(A^\pi(s, a) = q_\pi(s, a) - v_\pi(s)\)：优势函数。
- \(\gamma \in [0, 1)\)：折扣因子。\(\gamma = 1\) 只在保证终止的片段式任务中使用。
- \(\alpha\)：学习率（步长）。
- \(d_\pi(s)\)：策略 \(\pi\) 诱导的（折扣）状态占用度量。

凡是课件里写成 \(V, Q\) 的地方，本路线在推导中用小写 \(v, q\) 表示真实量，用 \(\hat{v}, Q\) 表格或 \(v_w, q_w\) 表示估计量。读课件时把两者对上即可。

### 0.4 先不要做的事

- 不要第一周就上 DQN / PPO。没有 Bellman 和 on-policy / off-policy 的直觉，深度代码只会变成调参。
- 不要跳过多臂老虎机。探索–利用是后面 \(\varepsilon\)-greedy、UCB、熵正则、随机策略的共同源头。
- 不要只看伪代码不手推更新式。每个算法至少在 2×2 或 4×4 格子上算三步。
- 不要把“能跑通 Gym”当成“学会了”。跑通只是工程门槛，能解释一条曲线为什么抖、为什么崩，才算过关。

## 第 1 章  强化学习简介与探索–利用

### 1.1 本章要达到的程度

学完本章，应能不看笔记回答下面六个问题。

1. 预测任务和决策任务差在哪里？
2. 强化学习的三个要素（感知、行动、目标）如何对应到 \((O_t, A_t, R_t)\)？
3. 历史、状态、马尔可夫状态有何区别？
4. 策略、价值、模型各自回答什么问题？
5. 基于价值、基于策略、Actor-Critic 三类方法如何划分？
6. 多臂老虎机的 regret 下界是什么，\(\varepsilon\)-greedy、UCB、Thompson Sampling 各自如何折中探索与利用？

### 1.2 预测与决策

课件把人工智能任务分成两类。

- **预测型任务**：根据数据给出信号。监督学习从 \((x, y)\) 学 \(f(x)\approx y\)；无监督学习从 \(x\) 学结构。预测不直接改变世界，用不用、怎么用，由人决定。
- **决策型任务**：智能体在动态环境中采取行动，行动改变下一状态，并得到即时奖励，目标是最大化长期累积奖励。课件原句：*Learning from interaction in a trial-and-error manner*。

一个对照：智慧医疗里，模型告诉医生“该病人患某病的概率是 0.82”，这是预测；模型直接下达用药方案并承担后果，这是决策。决策改变环境，未来分布随之改变，所以强化学习的数据不是固定数据集，而是 **策略依赖的数据流**。

这一点会贯穿全书：换策略就会换数据分布。这是后面 off-policy、occupancy measure、协变量偏移、离线外延误差的共同根源。

### 1.3 序贯决策

绝大多数强化学习问题都是序贯决策：决策者连续做决策，每一步看到新观测，直到任务结束或无限进行。形式上一局（episode）是

\[
O_0, A_0, R_1, O_1, A_1, R_2, \ldots, O_{T-1}, A_{T-1}, R_T
\]

或在完全可观测时把 \(O_t\) 写成 \(S_t\)。无限视界则没有终止时刻 \(T\)。

课件案例：Kendall 等人 *Learning to Drive in a Day*（ICRA 2019）用单目相机在真实车辆上做车道保持，奖励来自对车道中心的偏离，一天内学会驾驶。它说明三件事：状态可以是高维像素；奖励必须精心设计；真实世界交互昂贵，所以后面会需要仿真、离线数据和世界模型。

### 1.4 智能体–环境交互

在每一步 \(t\)：

- 智能体获得观测 \(O_t\) 和奖励 \(R_t\)，执行动作 \(A_t\)。
- 环境接收 \(A_t\)，给出 \(O_{t+1}\) 和 \(R_{t+1}\)。时间在环境这一侧递增。

把交互画成闭环：

```
        A_t
 Agent ------> Environment
       <------
     O_{t+1}, R_{t+1}
```

监督学习的数据来自固定分布 \(p_{\mathrm{data}}(x,y)\)。强化学习的数据来自

\[
\tau \sim p_\pi(\tau) = p(s_0)\prod_{t=0}^{T-1} \pi(a_t\mid s_t)\, p(s_{t+1}\mid s_t, a_t)
\]

策略 \(\pi\) 一变，轨迹分布 \(p_\pi\) 就变。这是“Agent 不同，交互出的数据也不同”那张课件的数学含义。

### 1.5 历史、状态、马尔可夫性

**历史**是到目前为止所有可观测变量：

\[
H_t = (O_0, A_0, R_1, O_1, \ldots, A_{t-1}, R_t, O_t)
\]

**状态**是用于决定下一步会发生什么的信息，是历史的函数 \(S_t = f(H_t)\)。

- 环境状态 \(S_t^e\)：环境内部用来产生下一观测和奖励的信息。
- 智能体状态 \(S_t^a\)：智能体用来选动作的信息。
- 信息状态 / 马尔可夫状态：满足

\[
\Pr(S_{t+1}, R_{t+1} \mid S_t, A_t) = \Pr(S_{t+1}, R_{t+1} \mid H_t, A_t)
\]

即“给定现在，未来与过去独立”。课件引用：*The future is independent of the past given the present*。

若 \(O_t = S_t^e\)，环境完全可观测，问题是 MDP。若智能体只能看到部分信息，问题是 POMDP，智能体状态通常要用 RNN 或信念 \(b(s) = \Pr(S_t^e \mid H_t)\) 来构造。本课程主体在 MDP，第 6 章和第 8 章会提到部分可观测时策略梯度仍然形式成立。

### 1.6 策略、奖励、价值、模型

强化学习系统四个可学习组件。

**策略 \(\pi\)**：从状态到动作的映射。

- 确定性：\(a = \pi(s)\)。
- 随机性：\(\pi(a\mid s) = \Pr(A=a\mid S=s)\)。

**奖励 \(R\)**：标量，立刻告诉“这一步好不好”。奖励是目标的定义，不是算法自己学出来的东西。Reward hypothesis（Sutton）：所有目标都可以写成最大化期望累积奖励。

**价值函数**：对长期回报的预测。

\[
v_\pi(s) = \mathbb{E}_\pi\!\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \,\middle|\, S_t = s\right]
\]

即时奖励短视，价值有远见。控制问题的本质往往是“先把价值估准，再对价值贪心”。

**模型**：对环境动力学的估计 \(\hat{p}(s', r \mid s, a)\)。有模型就可以做规划（第 5、9 章）；没有模型就只能从交互样本里学习（第 3、4 章）。

迷宫例子把四者钉死：状态是格子位置；动作是 {N,E,S,W}；撞墙则不动；每步奖励 \(-1\)，直到到达目标。最优策略就是最短路。Atari 例子则是另一极：规则未知，观测是像素，动作是手柄，奖励是分数变化。

### 1.7 三类方法

课件的三分法：

| 类型 | 学什么 | 不显式学什么 | 代表 |
|---|---|---|---|
| 基于价值 | \(q(s,a)\) 或 \(v(s)\) | 策略（由 greedy / \(\varepsilon\)-greedy 隐含） | Q-learning, DQN |
| 基于策略 | \(\pi_\theta(a\mid s)\) | 价值 | REINFORCE |
| Actor-Critic | 策略 + 价值 | — | A2C, PPO, DDPG, SAC |

表格型价值是一张 \(|\mathcal{S}|\times|\mathcal{A}|\) 的表。状态变成图像后，表存不下，就用神经网络做函数近似，于是进入深度强化学习。2013 年 NIPS workshop 的 Atari DQN 论文是分界点；2015 年 Nature DQN 用经验回放和目标网络把训练稳住。

深度强化学习带来的新困难（课件第 34 页，后面第 7 章会展开）：

- 参数空间极高维，训练不稳定。
- 数据非 i.i.d.、非稳态。
- 容易过拟合到近期轨迹。
- 需要大量交互和 CPU/GPU 分工。

### 1.8 探索与利用：问题陈述

在不知道各动作真实期望收益时，每一步都要在两件事之间选择：

- **利用（exploitation）**：选当前估计最好的动作，拿已知收益。
- **探索（exploration）**：选不确定的动作，可能发现更好的臂，也可能更差。

若永远利用，可能锁死在次优臂；若永远探索，则把时间浪费在已知更差的臂上。这是序贯决策的基本张力，不是实现细节。

### 1.9 多臂老虎机形式化

\(K\) 个臂（动作）。每一步选 \(A_t \in \{1,\ldots,K\}\)，收到独立奖励 \(R_t\)，期望为 \(q_*(a) = \mathbb{E}[R_t \mid A_t = a]\)。没有状态转移，所以是 MDP 的退化：\(|\mathcal{S}|=1\)。最优臂 \(a_* = \arg\max_a q_*(a)\)，最优期望 \(v_* = q_*(a_*)\)。

**增量均值估计。** 令 \(N_t(a)\) 为到 \(t\) 为止臂 \(a\) 被拉次数，\(Q_t(a)\) 为样本均值。新观测 \(R\) 到来时：

\[
Q_{n+1} = Q_n + \frac{1}{n}\bigl(R_n - Q_n\bigr)
\]

推导：\(Q_{n+1} = \frac{1}{n}\sum_{i=1}^n R_i = \frac{1}{n}\bigl((n-1)Q_n + R_n\bigr) = Q_n + \frac{1}{n}(R_n - Q_n)\)。这是后文所有 TD 更新 \(Q \leftarrow Q + \alpha(G - Q)\) 的原型。\(\alpha = 1/n\) 对应样本均值；固定 \(\alpha\) 对应指数滑动平均，适合非稳态。

### 1.10 Regret 与 Lai–Robbins 下界

单步 regret：\(\Delta_a = v_* - q_*(a)\)。到时刻 \(T\) 的累积 regret：

\[
L_T = T v_* - \sum_{t=1}^T q_*(A_t) = \sum_a \Delta_a \mathbb{E}[N_T(a)]
\]

目标是让 \(L_T\) 亚线性增长，即平均 regret \(L_T / T \to 0\)。

**Lai & Robbins (1985) 下界**（课件第 62 页）：对一致好的策略，次优臂 \(a\) 的拉动次数满足

\[
\liminf_{T\to\infty} \frac{\mathbb{E}[N_T(a)]}{\log T} \ge \frac{1}{\mathrm{KL}(q_a \,\|\, q_{a_*})}
\]

因此 \(L_T = \Omega(\log T)\)。没有任何算法能在不付出对数级探索代价的前提下保证找到最优臂。贪心策略的 regret 是线性的：一旦锁错臂，每步都付出常数 \(\Delta\)。

### 1.11 \(\varepsilon\)-greedy、衰减 \(\varepsilon\)、乐观初始化

**\(\varepsilon\)-greedy。** 以 \(1-\varepsilon\) 选 \(\arg\max_a Q(a)\)，以 \(\varepsilon\) 均匀随机。期望上每个臂被探索的频率至少 \(\varepsilon/K\)。固定 \(\varepsilon\) 的总 regret 仍线性，只是斜率比纯贪心小（课件第 63 页）。

**衰减 \(\varepsilon_t\)。** 令 \(\varepsilon_t \propto 1/t\) 或 \(1/\sqrt{t}\)，探索逐渐减少。适当衰减可达到对数 regret，但常数和衰减日程需要调。

**乐观初始化。** 把 \(Q_1(a)\) 设得明显高于可能的真实值（例如奖励上界）。早期每次利用都在“打破乐观”，等价于系统性探索。简单、无额外超参，对表格型很有效，对函数近似则要小心。

### 1.12 UCB：从 Hoeffding 到上置信界

设奖励在 \([0,1]\)。Hoeffding 不等式：对 i.i.d. 样本均值 \(\bar{X}\)，

\[
\Pr\bigl(\mathbb{E}[X] > \bar{X} + u\bigr) \le e^{-2 n u^2}
\]

令右端为 \(p = t^{-4}\)（或其他多项式），解出

\[
u = \sqrt{\frac{\log t}{2 N_t(a)}} \quad \text{（常把常数吸收进 } c\text{）}
\]

UCB1 选择

\[
A_t = \arg\max_a \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]
\]

第一项是利用，第二项是对不确定性的奖励：拉得少的臂 \(N_t(a)\) 小，置信上界高，会被优先探索。课件写“显式地鼓励不确定性”。UCB 达到 \(O(\log T)\) regret，与 Lai–Robbins 下界同阶。

直觉选择：三个臂的 \(Q\) 接近但方差（或访问次数）不同时，选置信上界最高者，不是选均值最高者。

### 1.13 Thompson Sampling

想法：按“该臂是最优臂的后验概率”来选动作。对伯努利老虎机，设臂 \(a\) 的成功概率 \(\theta_a \sim \mathrm{Beta}(\alpha_a, \beta_a)\)，先验 \(\mathrm{Beta}(1,1)\)（均匀）。每次：

1. 从每个臂的后验抽一个 \(\tilde{\theta}_a\)。
2. 选 \(A_t = \arg\max_a \tilde{\theta}_a\)。
3. 观测 \(R_t\in\{0,1\}\)，更新 \(\alpha \leftarrow \alpha+R_t\)，\(\beta \leftarrow \beta+(1-R_t)\)。

这是贝叶斯探索：后验越尖，抽样越集中在利用；后验越散，抽样越可能探索。Chapelle & Li (NIPS 2011) 的实验（课件第 73–74 页）表明，在 \(K\) 臂、最优臂概率 0.5、其余 \(0.5-\varepsilon\) 的设置下，TS 的 regret 接近渐近下界，通常优于 UCB。

Beta 密度：

\[
p(\theta) = \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} \theta^{\alpha-1}(1-\theta)^{\beta-1}, \quad \mathbb{E}[\theta]=\frac{\alpha}{\alpha+\beta}
\]

\(\alpha\) 可理解为成功次数加一，\(\beta\) 为失败次数加一。

### 1.14 从老虎机到 MDP 的桥

老虎机没有状态。MDP 的每个状态都可以看成一个“上下文老虎机”：在 \(s\) 下选 \(a\)，但下一状态会变，所以不能只用即时奖励，必须用 \(q(s,a)\)。于是：

- \(\varepsilon\)-greedy 直接搬到 SARSA / Q-learning。
- UCB 出现在带计数的探索奖励、以及 Dyna-Q+ 的探索bonus。
- Thompson Sampling 对应后验采样 / PSRL。
- 随机策略本身就是一种持续探索（SAC 的熵项、\(\varepsilon\) 不会衰减到 0 的 on-policy 方法）。

## 第 2 章  马尔可夫决策过程与动态规划

> 对应课件：`2-马尔可夫决策过程.pptx`（39 页）  
> 教材：Sutton & Barto 第 3、4 章；Silver Lecture 2–3  
> 可视化：HTML 模块「格子世界」「Bellman 备份」

### 2.1 从随机过程到 MDP

随机过程研究随时间演化的随机现象。马尔可夫过程（Markov Process / Markov Chain）是状态序列 \((S_t)\) 满足马尔可夫性：

\[
\Pr(S_{t+1}\mid S_t, S_{t-1}, \ldots, S_0) = \Pr(S_{t+1}\mid S_t)
\]

MDP 在马尔可夫过程上加入动作和奖励，为“结果部分随机、部分由决策者控制”的过程提供数学框架。课件强调：MDP 描述的是 **完全可观测** 的强化学习环境。

### 2.2 MDP 五元组

\[
\mathcal{M} = \bigl(\mathcal{S}, \mathcal{A}, p, r, \gamma\bigr)
\]

有时把初始分布 \(p_0(s)\) 或奖励函数的随机性单独写出，成为六元组。分量含义：

1. \(\mathcal{S}\)：状态集合。
2. \(\mathcal{A}\)：动作集合。可依赖状态，写成 \(\mathcal{A}(s)\)。
3. \(p(s'\mid s, a) = \Pr(S_{t+1}=s'\mid S_t=s, A_t=a)\)：转移核。
4. \(r(s,a) = \mathbb{E}[R_{t+1}\mid S_t=s, A_t=a]\)，或更细的 \(r(s,a,s')\)。
5. \(\gamma \in [0,1)\)：折扣。把远期奖励压下来，也保证无限视界期望有界。

若奖励是随机的，完整动力学是 \(p(s', r \mid s, a)\)。两者关系：

\[
p(s'\mid s,a) = \sum_r p(s', r \mid s, a), \qquad
r(s,a) = \sum_{s',r} r\, p(s', r \mid s, a)
\]

### 2.3 回报与目标

有限视界：

\[
G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}
\]

无限视界：

\[
G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
\]

递归展开（这是所有 Bellman 方程的种子）：

\begin{align}
G_t
&= R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots \\
&= R_{t+1} + \gamma \bigl(R_{t+2} + \gamma R_{t+3} + \cdots\bigr) \\
&= R_{t+1} + \gamma G_{t+1}
\end{align}

学习目标：找策略 \(\pi\) 最大化

\[
J(\pi) = \mathbb{E}_{s_0 \sim p_0,\, \tau \sim \pi}\bigl[G_0\bigr] = \mathbb{E}_{s_0}\bigl[v_\pi(s_0)\bigr]
\]

### 2.4 占用度量（Occupancy Measure）

课件第 12–15 页引入占用度量，来源是 Syed, Bowling, Schapire, ICML 2008。给定策略 \(\pi\)，折扣状态占用

\[
d_\pi(s) = (1-\gamma)\sum_{t=0}^{\infty} \gamma^t \Pr(S_t = s \mid \pi)
\]

状态–动作占用

\[
\rho_\pi(s,a) = d_\pi(s)\, \pi(a\mid s)
\]

它满足流守恒（Bellman flow）：

\[
d_\pi(s') = (1-\gamma) p_0(s') + \gamma \sum_{s,a} d_\pi(s)\, \pi(a\mid s)\, p(s'\mid s,a)
\]

策略的期望回报可以写成对即时奖励的线性函数：

\[
J(\pi) = \frac{1}{1-\gamma} \sum_{s,a} \rho_\pi(s,a)\, r(s,a)
\]

课件说“强化学习中的简写”指的就是用 \(\rho_\pi\) 把轨迹期望变成 \((s,a)\) 空间上的加权和。这在模仿学习（匹配专家占用）、off-policy 评估、以及把 RL 写成线性规划时会反复出现。

关键事实：**占用度量与策略一一对应**（在适当条件下）。优化 \(\pi\) 等价于在可行占用集合上优化 \(\rho\)。可行集由上述流守恒和 \(\rho\ge 0\) 刻画，这是 LP 形式的 RL。

### 2.5 价值函数的定义

状态价值：

\[
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]
\]

动作价值：

\[
q_\pi(s,a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]
\]

用奖励函数写出（习题第 1 题）：

\begin{align}
v_\pi(s)
&= \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \mid S_t=s\right] \\
q_\pi(s,a)
&= \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \mid S_t=s, A_t=a\right]
\end{align}

它们的含义：\(v_\pi(s)\) 是“在 \(s\) 按 \(\pi\) 一直走下去有多好”；\(q_\pi(s,a)\) 是“在 \(s\) 先做 \(a\)，之后再按 \(\pi\) 走有多好”。

### 2.6 \(v\) 与 \(q\) 的互表（习题第 2 题）

由定义，对 \(v\) 把第一步动作边缘化：

\[
v_\pi(s) = \sum_{a} \pi(a\mid s)\, q_\pi(s,a)
\]

对 \(q\) 把一步转移写开：

\[
q_\pi(s,a) = r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, v_\pi(s')
\]

两式互代，得到下一小节的 Bellman 期望方程。确定性策略时 \(v_\pi(s) = q_\pi(s, \pi(s))\)。

### 2.7 Bellman 期望方程（习题第 3 题）

把 \(G_t = R_{t+1} + \gamma G_{t+1}\) 取条件期望，用马尔可夫性和策略，得到

\begin{align}
v_\pi(s)
&= \sum_a \pi(a\mid s)\left[
     r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, v_\pi(s')
   \right] \\
q_\pi(s,a)
&= r(s,a) + \gamma \sum_{s'} p(s'\mid s,a) \sum_{a'} \pi(a'\mid s')\, q_\pi(s', a')
\end{align}

**逐步推导 \(v_\pi\)。**

1. \(v_\pi(s) = \mathbb{E}_\pi[R_{t+1} + \gamma G_{t+1} \mid S_t=s]\)。
2. 全期望公式对 \(A_t\) 展开：\(\sum_a \pi(a\mid s)\, \mathbb{E}_\pi[R_{t+1}+\gamma G_{t+1}\mid S_t=s, A_t=a]\)。
3. 内层对 \((S_{t+1}, R_{t+1})\) 用 \(p\)：\(\sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\bigl[r + \gamma \mathbb{E}_\pi[G_{t+1}\mid S_{t+1}=s']\bigr]\)。
4. \(\mathbb{E}_\pi[G_{t+1}\mid S_{t+1}=s'] = v_\pi(s')\)，奖励期望并入 \(r(s,a)\)。

矩阵形式：令 \(P^\pi(s,s') = \sum_a \pi(a\mid s)p(s'\mid s,a)\)，\(r^\pi(s)=\sum_a \pi(a\mid s)r(s,a)\)，则

\[
v_\pi = r^\pi + \gamma P^\pi v_\pi
\quad\Rightarrow\quad
v_\pi = \bigl(I - \gamma P^\pi\bigr)^{-1} r^\pi
\]

\(\gamma<1\) 时 \(I-\gamma P^\pi\) 可逆，解唯一。这是“策略评估有闭式解”的原因，也是动态规划能做精确评估的原因。

课件第 20 页把方程拆成四块：**立即奖励、时间折扣、状态转移、下一状态价值**。备份图（backup diagram）从 \(s\) 画出所有 \(a\)、所有 \(s'\)，再回到 \(v(s')\)。动态规划做 **完全备份**（所有后继都算）；MC/TD 做 **采样备份**。

### 2.8 最优价值与 Bellman 最优方程

最优状态价值：

\[
v_*(s) = \max_\pi v_\pi(s)
\]

最优动作价值：

\[
q_*(s,a) = \max_\pi q_\pi(s,a)
\]

Bellman 最优方程把 \(\max\) 放进备份：

\begin{align}
v_*(s)
&= \max_a \left[
     r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, v_*(s')
   \right] \\
q_*(s,a)
&= r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, \max_{a'} q_*(s', a')
\end{align}

关系：\(v_*(s) = \max_a q_*(s,a)\)。最优策略可取

\[
\pi_*(s) \in \arg\max_a q_*(s,a)
\]

可以是确定性的。存在性：有限 MDP 至少存在一个确定性最优策略。

**最优方程是非线性的**（有 \(\max\)），一般没有像 \((I-\gamma P^\pi)^{-1}\) 那样的线性闭式，需要迭代。

### 2.9 策略评估（迭代）

已知 \(\pi\)，求 \(v_\pi\)。同步迭代：

\[
v_{k+1}(s) = \sum_a \pi(a\mid s)\left[
  r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, v_k(s')
\right]
\]

即 \(v_{k+1} = r^\pi + \gamma P^\pi v_k\)。这是以 \(\gamma\) 为压缩系数的仿射映射，Banach 不动点定理保证从任意 \(v_0\) 收敛到 \(v_\pi\)。误差

\[
\|v_{k+1}-v_\pi\|_\infty \le \gamma \|v_k - v_\pi\|_\infty
\]

所以每步误差至少乘 \(\gamma\)。课件格子世界例子：\(k=0\) 全零，\(k=1,2,3,10,\infty\) 价值从起点向外“渗”。

### 2.10 策略改进定理（第 5 章课件给出完整证明，这里先用）

给定 \(v_\pi\)，定义贪心策略

\[
\pi'(s) \in \arg\max_a q_\pi(s,a)
\]

**策略改进定理。** 若对所有 \(s\)，\(q_\pi(s, \pi'(s)) \ge v_\pi(s)\)，则 \(v_{\pi'} \ge v_\pi\)；若存在某个状态严格大于，则 \(v_{\pi'}\) 在该处严格改进。

**证明（逐步展开）。** 对任意 \(s\)，

\begin{align}
v_\pi(s)
&\le q_\pi(s, \pi'(s)) \\
&= \mathbb{E}[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t=s, A_t=\pi'(s)] \\
&\le \mathbb{E}[R_{t+1} + \gamma q_\pi(S_{t+1}, \pi'(S_{t+1})) \mid \ldots] \\
&\le \mathbb{E}_{\pi'}[R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots] \\
&= v_{\pi'}(s)
\end{align}

每一步都把 \(v_\pi\) 换成更大的 \(q_\pi(\cdot,\pi'(\cdot))\)，无限展开后正好是 \(\pi'\) 的回报。这一定理是策略迭代、GPI、以及“先评估再改进”整条值方法路线的合法性来源。

### 2.11 策略迭代

在策略评估和策略改进之间交替：

1. **策略评估：** 迭代或精确求解 \(v_{\pi_k}\)。
2. **策略改进：** \(\pi_{k+1}(s) = \arg\max_a q_{\pi_k}(s,a)\)。
3. 若 \(\pi_{k+1}=\pi_k\)，停止；否则 \(k\leftarrow k+1\)。

有限 MDP 中确定性策略有限，单调改进且不循环，故有限步到达最优。课件备注：小 MDP 策略迭代通常很快；每次精确评估要解线性系统，大 MDP 上昂贵。

**贪心改进不必等评估完全收敛。** 只扫一两遍就改进，就是截断策略迭代，极限情况每状态只备份一次再贪心，变成价值迭代。

### 2.12 价值迭代

直接在最优方程上迭代：

\[
v_{k+1}(s) = \max_a \left[
  r(s,a) + \gamma \sum_{s'} p(s'\mid s,a)\, v_k(s')
\right]
\]

等价于 \(v_{k+1} = \mathcal{T} v_k\)，其中 \(\mathcal{T}\) 是 Bellman 最优算子。\(\mathcal{T}\) 是 \(\gamma\)-压缩：

\[
\|\mathcal{T}u - \mathcal{T}w\|_\infty \le \gamma \|u-w\|_\infty
\]

因此唯一不动点 \(v_*\)，价值迭代从任意初值收敛到 \(v_*\)。得到 \(v_*\) 后，

\[
\pi_*(s) \in \arg\max_a \left[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_*(s')\right]
\]

课件第 31 页最短路例子：每步奖励 \(-1\)，价值迭代就是从目标往外刷最短距离。

**同步 vs 异步。** 同步：用旧表算完整张新表再替换。异步：原地更新，Gauss–Seidel 式，通常更快。实时动态规划（第 5 章 RTDP）只更新当前轨迹碰到的状态，是异步价值迭代的在线版。

### 2.13 价值迭代 vs 策略迭代（课件第 32 页）

- 价值迭代是“贪心更新”，每步评估不彻底。
- 策略迭代中用 Bellman 等式把价值评估到底，代价大。
- 状态空间小：策略迭代往往更少轮就收敛。
- 状态空间大：价值迭代更实用。
- 若转移无环（DAG），按拓扑序扫一遍价值迭代即可精确，不必多轮。

广义策略迭代（GPI）把两者放在同一张图里：评估让 \(v\) 靠近当前 \(\pi\) 的 \(v_\pi\)，改进让 \(\pi\) 靠近当前 \(v\) 的贪心策略。两者同时动，互相追逐，直到一致于 \((v_*,\pi_*)\)。SARSA、Q-learning、Actor-Critic 都是 GPI 的近似实现。

### 2.14 动态规划的收缩与收敛（补课件公式）

定义 Bellman 期望算子 \(\mathcal{T}^\pi\) 和最优算子 \(\mathcal{T}\)：

\begin{align}
(\mathcal{T}^\pi v)(s)
&= \sum_a \pi(a\mid s)\bigl[r(s,a)+\gamma \sum_{s'}p(s'\mid s,a)v(s')\bigr] \\
(\mathcal{T} v)(s)
&= \max_a \bigl[r(s,a)+\gamma \sum_{s'}p(s'\mid s,a)v(s')\bigr]
\end{align}

对任意 \(u,w\) 和任意 \(s\)，

\[
\bigl|(\mathcal{T}u)(s)-(\mathcal{T}w)(s)\bigr|
\le \gamma \max_{s'} |u(s')-w(s')|
\]

因为 \(\max_a f_a - \max_a g_a \le \max_a (f_a-g_a)\)。于是 \(\|\mathcal{T}u-\mathcal{T}w\|_\infty\le\gamma\|u-w\|_\infty\)。同理 \(\mathcal{T}^\pi\) 也是 \(\gamma\)-压缩。Banach 不动点定理给出存在唯一、线性收敛。Q-learning 的收敛证明（第 4 章）本质上是随机近似版本的压缩映射。

### 2.15 与监督学习的区别（习题第 4 题）

| | 监督学习 | 强化学习 |

| 数据 | 固定 i.i.d. \((x,y)\) | 策略依赖的轨迹 |

## 第 3 章  值函数估计（无模型预测）

> 对应课件：`3-值函数估计.pptx`（35 页）  
> 教材：Sutton & Barto 第 5、6 章  
> 可视化：HTML 模块「MC vs TD」

### 3.1 无模型意味着什么

动态规划需要 \(p(s'\mid s,a)\)。无模型强化学习把环境当黑盒：只能通过交互得到 \((S_t, A_t, R_{t+1}, S_{t+1})\)。本章只做 **预测**（给定 \(\pi\)，估 \(v_\pi\) 或 \(q_\pi\)），下一章做 **控制**（同时改策略）。

课件原话：要优化策略，首要任务是精准、高效地估计状态或状态–动作价值。无模型估计的两条主干是蒙特卡洛（MC）和时序差分（TD）。

### 3.2 蒙特卡洛策略评估

思想：用经验平均回报代替期望回报。对每个出现过的状态 \(s\)，收集所有以 \(s\) 为起点的回报样本 \(G^{(1)}, G^{(2)}, \ldots\)，

\[
\hat{v}(s) = \frac{1}{N(s)}\sum_{i=1}^{N(s)} G^{(i)}
\]

**First-visit MC：** 每个片段里 \(s\) 第一次出现才计入。无偏。  
**Every-visit MC：** 每次出现都计入。有偏但偏差随访问趋于 0，常更高效。

增量形式（与第 1 章同一公式）：

\[
V(S_t) \leftarrow V(S_t) + \alpha\bigl(G_t - V(S_t)\bigr)
\]

\(\alpha=1/N(S_t)\) 时即样本均值。MC 必须等到片段结束才知道 \(G_t\)，因此不能用于持续性（non-episodic）任务。

### 3.3 时序差分学习 TD(0)

TD 把 MC 的目标 \(G_t\) 换成 **自助目标** \(R_{t+1}+\gamma V(S_{t+1})\)：

\[
V(S_t) \leftarrow V(S_t) + \alpha\bigl[
  R_{t+1} + \gamma V(S_{t+1}) - V(S_t)
\bigr]
\]

括号内是 TD 误差

\[
\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)
\]

它是对 \(G_t - V(S_t)\) 的一步估计。课件说：TD 用“对未来的猜测”代替“观测到的最终结果”。

**逐步看出它在估 Bellman 方程。** Bellman 期望方程说 \(v_\pi(s)=\mathbb{E}[R_{t+1}+\gamma v_\pi(S_{t+1})\mid s]\)。TD(0) 用样本 \(R_{t+1}+\gamma V(S_{t+1})\) 做随机近似。若 \(V=v_\pi\)，则 \(\mathbb{E}[\delta_t\mid S_t]=0\)。

### 3.4 驾车回家例子（课件第 23 页）

状态序列：离开公司 → 下雨 → 离开高速 → 跟卡车 → 到家所在街道 → 到家。每行有“已经过时间”和“预计剩余”，两者相加是“预计总时间”。

- MC：只有到家之后才知道真实总时长 43 分钟，然后把沿途每个状态的估计一次更新到 43。
- TD：每到一个新状态就用新的“已过 + 预计剩余”去修正上一个状态。下雨时总预计从 30 变成 40，立刻把“离开公司”的估计往上调。

TD 能在知道最终结果之前学习；MC 必须等片段结束。TD 能从不完整序列学习，也能用于没有终止的持续任务。

### 3.5 偏差与方差（习题第 5 题）

| | 目标 | 偏差 | 方差 | 需要终止 | 对初始值 |
|---|---|---|---|---|---|
| MC | \(G_t\)（真实回报） | 无偏（first-visit） | 高（整条轨迹的随机性） | 是 | 不敏感 |
| TD(0) | \(R+\gamma V(S')\) | 有偏（\(V\) 不准时） | 低（只一步随机） | 否 | 敏感 |
| DP | 完全备份 | 无采样偏差，但依赖模型 | 无采样方差 | 否 | 敏感 |

MC：良好收敛性，函数近似下也较稳，易理解。  
TD：通常更高效，实际中更常见（课件总结原句）。

两者都是无偏 Bellman 方程的不同近似：MC 近似外层期望（用整段回报），TD 还用当前 \(V\) 近似内层 \(v_\pi(S')\)。

### 3.6 随机游走数值事实

Sutton 书中 5 状态随机游走（课件第 27–28 页）：TD 在少量片段后的 RMS 误差通常低于 MC，因为低方差。但 \(\alpha\) 过大时 TD 会振荡。这提示：TD 的优势不是绝对的，取决于步长和数据量。

### 3.7 备份图谱系

课件第 29–33 页对应 Silver 的那张总图：

- DP：宽备份，用模型对所有后继求期望。
- TD：浅备份，一步采样。
- MC：深备份，一直采样到终止。
- n 步 TD：深度介于 1 和 \(\infty\) 之间。
- 资格迹 TD(\(\lambda\))：把不同 n 的目标指数加权平均。

### 3.8 n 步 TD（习题第 10 题的预测版）

n 步回报：

\[
G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})
\]

更新：\(V(S_t) \leftarrow V(S_t) + \alpha\bigl(G_{t:t+n} - V(S_t)\bigr)\)。

- \(n=1\)：TD(0)，偏差较大、方差较小。
- \(n\to\infty\)：MC，偏差小、方差大。
- 中间 \(n\) 往往最好。课件随机游走图：19 状态、10 个片段时，存在最优 \(n\)。

TD(\(\lambda\)) 的 \(\lambda\)-回报

\[
G_t^\lambda = (1-\lambda)\sum_{n=1}^{\infty} \lambda^{n-1} G_{t:t+n}
\]

用资格迹前向/后向实现，不必显式存所有 n。

### 3.9 重要性采样与 off-policy 预测

若数据来自行为策略 \(b\)，要评估目标策略 \(\pi\)，必须修正分布。轨迹重要性比：

\[
\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k\mid S_k)}{b(A_k\mid S_k)}
\]

Ordinary IS：\(\hat{v}(s) = \frac{\sum_i \rho^{(i)} G^{(i)}}{N}\)。  
Weighted IS：\(\hat{v}(s) = \frac{\sum_i \rho^{(i)} G^{(i)}}{\sum_i \rho^{(i)}}\)，方差更小。

MC 的 \(\rho\) 是整条轨迹的乘积，方差可爆炸。TD 只需单步比：

\[
V(S_t) \leftarrow V(S_t) + \alpha\left[
  \frac{\pi(A_t\mid S_t)}{b(A_t\mid S_t)}\bigl(R_{t+1}+\gamma V(S_{t+1})\bigr) - V(S_t)
\right]
\]

课件第 19 页：off-policy TD 的重要性采样修正方差低于 MC，因为策略只需在单步被近似。这是后面 off-policy Actor-Critic、Retrace、V-trace 的源头。

覆盖假设：\(b(a\mid s)>0\) 只要 \(\pi(a\mid s)>0\)。否则 IS 无定义。

## 第 4 章  无模型控制

> 对应课件：`4-无模型控制.pptx`（55 页）  
> 教材：Sutton & Barto 第 6.4–6.5、第 7 章  
> 可视化：HTML 模块「悬崖漫步」

### 4.1 从预测到控制

预测估 \(v_\pi\)。控制要找 \(\pi_*\)。无模型控制的 GPI 模板：

1. 用 MC 或 TD 估 \(q_\pi\)（动作价值，才能在不知道模型时做贪心）。
2. 对 \(q\) 做 \(\varepsilon\)-greedy 改进。

为什么必须是 \(q\) 而不是 \(v\)？因为无模型时不能对 \(\sum_{s'}p(s'\mid s,a)v(s')\) 求期望，无法从 \(v\) 直接算贪心动作。

### 4.2 SARSA：on-policy TD 控制

转换 \((S, A, R, S', A')\)，故名 SARSA：

\[
Q(S,A) \leftarrow Q(S,A) + \alpha\bigl[
  R + \gamma Q(S', A') - Q(S,A)
\bigr]
\]

\(A'\) 由 **当前策略**（通常 \(\varepsilon\)-greedy）选出。这是 on-policy：估的就是正在生成数据的策略的 \(q_\pi\)。

算法骨架：

```
初始化 Q(s,a)
对每个片段:
  初始化 S，由 π 从 S 选 A
  对片段中每一步:
    执行 A，观察 R, S'
    由 π 从 S' 选 A'
    Q(S,A) ← Q(S,A) + α[R + γ Q(S',A') − Q(S,A)]
    S ← S', A ← A'
```

课件 Windy Gridworld：每步 \(-1\)，无折扣，风把智能体向上吹。训练过程中到达目标越来越快。

### 4.3 Q-learning：off-policy TD 控制

\[
Q(S,A) \leftarrow Q(S,A) + \alpha\bigl[
  R + \gamma \max_{a'} Q(S', a') - Q(S,A)
\bigr]
\]

行为策略可以是 \(\varepsilon\)-greedy，目标却是贪心（最优）策略的 Bellman 最优方程。这是 off-policy：数据来自探索策略，学的是 \(q_*\)。

课件列出 off-policy 的动机（第 14 页，习题 12）：

- 平衡探索与利用。
- 从人类或其他智能体的数据学习。
- 重用旧策略经验。
- 跟随探索策略时学习最优策略。
- 跟随一个策略时学习多个策略。

### 4.4 悬崖漫步：为何两条曲线不同（课件第 23 页）

网格底部是悬崖：踏入得 \(-100\) 并回到起点；其它移动 \(-1\)；目标 0 终止。\(\varepsilon=0.1\)。

- **Q-learning** 学 \(q_*\)，最优路径贴着悬崖边，路程短。但 \(\varepsilon\)-greedy 执行时会以 0.1 概率掉下去，在线性能差。
- **SARSA** 学 \(\varepsilon\)-greedy 策略自己的 \(q_\pi\)，因此主动远离悬崖，路径更长但更安全，在线回报更好。

若把 \(\varepsilon\) 退火到 0，两者都应逼近最优贴边路径。这是 on-policy 与 off-policy 最经典的定性差别。

### 4.5 Q-learning 收敛（课件第 19–22 页）

参考 Melo, “Convergence of Q-learning: A simple proof”，以及《动手学强化学习》TD 章节。

**定理（表格型）。** 假设每个 \((s,a)\) 被访问无限次，步长满足 Robbins–Monro 条件

\[
\sum_t \alpha_t(s,a) = \infty, \qquad \sum_t \alpha_t(s,a)^2 < \infty
\]

则 \(Q_t \to q_*\) 以概率 1。

**压缩论点。** Bellman 最优算子 \(\mathcal{T}\) 在 \(\|\cdot\|_\infty\) 下是 \(\gamma\)-压缩，唯一不动点 \(q_*\)。Q-learning 是

\[
Q_{t+1}(s,a) = (1-\alpha_t) Q_t(s,a) + \alpha_t \bigl( r + \gamma \max_{a'} Q_t(s',a') \bigr)
\]

即带噪声的 \(\mathcal{T}\) 迭代。噪声的条件期望为零（给定当前 \(Q\) 和 \((s,a)\)，随机性只来自 \((r,s')\sim p\)）。随机近似理论给出收敛。

**直接从 Q 函数的证明思路（课件“直接从 Q 函数证明”）：** 考虑 \(\Delta_t = Q_t - q_*\)，证明 \(\|\Delta_t\|_\infty\) 的一个随机 Lyapunov 过程趋于 0。关键不等式：

\[
\bigl|\max_{a'} Q(s',a') - \max_{a'} q_*(s',a')\bigr| \le \max_{a'} |Q(s',a')-q_*(s',a')|
\]

从而备份算子的误差不超过 \(\gamma\|\Delta\|_\infty\)。

注意：函数近似下这些条件一般不成立，这就是第 6–7 章的“致命三要素”（off-policy + 自助 + 函数近似）。

### 4.6 多步控制：n 步 SARSA 与 n 步 Q-learning

n 步 SARSA 目标：

\[
G_{t:t+n} = R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{n-1}R_{t+n}+\gamma^n Q(S_{t+n}, A_{t+n})
\]

n 步期望 SARSA 把最后一项换成 \(\sum_a \pi(a\mid S_{t+n}) Q(S_{t+n}, a)\)，降低方差。

off-policy 多步需要重要性采样，或用树备份（tree-backup）把不匹配的动作改成期望分支，避免整条轨迹的 \(\rho\) 乘积。课件第 25 页四块：多步 TD 预测、多步 SARSA、带 IS 的多步 off-policy、多步树备份。

**习题 10：** \(n\) 越小越像 TD（偏差↑方差↓），\(n\) 越大越像 MC（偏差↓方差↑）。控制问题里 \(n\) 还影响“归责”速度：长程奖励要更大的 \(n\) 或 \(\lambda\) 才能传到早期动作。

### 4.7 期望 SARSA

\[
Q(S,A) \leftarrow Q(S,A)+\alpha\left[
  R+\gamma\sum_{a'}\pi(a'\mid S')Q(S',a') - Q(S,A)
\right]
\]

比 SARSA 方差小（对 \(A'\) 求了期望），比 Q-learning 更 on-policy。\(\pi\) 若是贪心，期望 SARSA 退化为 Q-learning。

### 4.8 习题 9：两套更新公式（默写）

SARSA：

\[
Q(s,a) \leftarrow Q(s,a)+\alpha\bigl[r+\gamma Q(s',a')-Q(s,a)\bigr]
\]

Q-learning：

\[
Q(s,a) \leftarrow Q(s,a)+\alpha\bigl[r+\gamma \max_{a'}Q(s',a')-Q(s,a)\bigr]
\]

差别只在 bootstrap 用的下一动作：当前策略的 \(a'\) vs 贪心 \(\max\)。

### 4.9 习题 13：一条轨迹上的目标值手算

给定轨迹在终止 \(T\) 处结束，\(\gamma\) 已知，初始 \(Q=0\)。设轨迹为

\[
S_0,A_0,R_1,S_1,A_1,R_2,\ldots,S_{T-1},A_{T-1},R_T, S_T=\text{terminal}
\]

1. **MC 目标**（对 \(t=0\)）：\(G_0 = \sum_{k=0}^{T-1}\gamma^k R_{k+1}\)。因为初始 \(Q=0\) 且 MC 不用 bootstrap。
2. **2 步 TD 目标**（对 \(t=0\)）：\(G_{0:2}= R_1 + \gamma R_2 + \gamma^2 Q(S_2, A_2)\)。若还没更新过，\(Q=0\)，则 \(G_{0:2}=R_1+\gamma R_2\)。

把课件表格里的具体数字代入即可得到数值答案。注意：若中途已经用同轨迹前面的转移更新过 \(Q\)，n 步目标里的 \(Q(S_2,A_2)\) 就不再是 0——手算时必须声明“沿轨迹在线更新”还是“批更新”。作业默认通常是用旧 \(Q\) 算目标。

### 4.10 习题 6–7：Q 表上的贪心动作

某时刻 Q 表（三动作）：

| | \(a_0\) | \(a_1\) | \(a_2\) |
|---|---|---|---|
| \(s_0\) | 1.0 | 0.3 | 2.2 |
| \(s_1\) | -0.3 | 0 | -1.5 |
| \(s_2\) | 3.0 | 2.0 | -2.0 |

贪婪策略：\(s_0\to a_2\)（2.2），\(s_1\to a_1\)（0），\(s_2\to a_0\)（3.0）。若 \(\varepsilon\)-greedy，则以 \(\varepsilon\) 概率在三个动作中均匀选。

### 4.11 习题 8：DP / TD / MC 对照

| | 备份 | 模型 | 深度 | 偏差/方差 |
|---|---|---|---|---|
| DP | 完全期望 | 需要 | 一步（可迭代） | 无采样方差 |
| TD | 采样 + 自助 | 不需要 | 浅 | 有偏、低方差 |
| MC | 采样到终止 | 不需要 | 深 | 无偏、高方差 |

DP 是规划，MC/TD 是学习。第 5 章会把规划用在模型生成的模拟经验上，于是 DP 与 TD 在同一套备份语言里会合。

## 第 5 章  规划与学习

> 对应课件：`5-规划与学习.pptx`（57 页）  
> 教材：Sutton & Barto 第 8 章  
> 可视化：HTML 模块「Dyna-Q」「MCTS」

### 5.1 规划与学习的同一套备份

课件引用海涅：“思想总是走在行动的前面”。规划是先在脑子（模型）里试，再出手。

- **学习：** 用真实环境产生的经验更新价值 / 策略。
- **规划：** 用模型产生的 **模拟经验** 做同样的备份。

两者的更新式可以完全相同。差别只在经验从哪来。因此 Dyna 能把 Q-learning 的一次真实更新，后面再接 \(N\) 次模拟更新。

### 5.2 模型的两种形态

- **分布模型：** 给出 \(p(s',r\mid s,a)\) 的全体。DP 需要这种。
- **样本模型：** 只能从 \(p\) 里抽出一个 \((s',r)\)。随机模拟器、神经网络动力学都是样本模型。

骰子例子：分布模型列出所有点数和概率；样本模型掷一次得到一个和。规划用模型生成模拟经验，再像无模型方法那样更新。

### 5.3 规划的分类

- **状态空间规划：** 在 \(\mathcal{S}\) 上搜策略。本课主体（DP、Dyna、MCTS）。
- **规划空间规划：** 状态是一个“计划”（动作集合+顺序约束），用遗传算法或偏序规划搜计划。

通用框架：模型 → 模拟数据 → 更新价值 → 改进策略。可随时打断，适合复杂问题里做增量规划。

### 5.4 策略改进定理的启示（课件第 7–9 页）

第 2 章已证 \(v_{\pi'}\ge v_\pi\)。启示：

1. 不必一次改到最优，局部贪心也能单调改进。
2. 评估不必完美，只要 \(q\) 的排序对，改进方向就对。
3. 规划时间可以花在“当前策略会访问的状态”上（轨迹采样、RTDP），而不必扫全表。

### 5.5 Dyna-Q

Sutton 1991。真实经验同时做三件事：

1. **直接 RL：** 用 \((s,a,r,s')\) 做 Q-learning 更新。
2. **模型学习：** 表格环境里存 \(\mathrm{Model}(s,a)\leftarrow (s',r)\)（确定性）或频率统计（随机）。
3. **规划：** 从曾经见过的 \((s,a)\) 均匀抽样，用模型生成 \((\hat{s}',\hat{r})\)，再做同样的 Q 更新。

迷宫里 Dyna-Q 比纯 Q-learning 快得多：一次走路，脑子里把这条路上的价值来回备份很多遍。

**Dyna-Q+：** 给长期未访问的 \((s,a)\) 加探索奖励 \(\kappa\sqrt{\tau}\)，\(\tau\) 是距上次访问的时间。用于环境变化：障碍迷宫（1000 步后墙右移）、捷径迷宫（3000 步后出现近路）。课件结论：Dyna-Q+ 能发现捷径，普通 Dyna-Q 可能还在用旧模型。

模型不准的三种来源（课件第 26 页）：随机环境样本不足；函数近似泛化差；环境已变但模型未检测。

### 5.6 优先级扫描

不是均匀抽 \((s,a)\)，而是优先更新“紧急”的状态。PQueue 的键是 TD 误差绝对值

\[
p = \bigl| r + \gamma \max_{a'} Q(s',a') - Q(s,a) \bigr|
\]

更新 \(s\) 后，把它的前驱状态（能一步到 \(s\) 的格子）入堆。价值变化沿可能的路径 **反向传播**。迷宫实验：横轴格子世界大小，纵轴收敛所需更新次数，优先级扫描明显更少。

局限：随机环境里对低概率转移做期望更新浪费计算，可改用采样更新。

### 5.7 期望更新 vs 采样更新

| | 期望更新 | 采样更新 |
|---|---|---|
| 需要 | 分布模型 | 样本模型 |
| 计算 | 对所有 \(s'\) 求和 | 一次抽样 |
| 偏差 | 无采样偏差 | 有采样误差 |

分支因子大时，采样更新的计算性价比更高，并逼近期望更新的效果（课件第 38 页）。轨迹采样则按当前策略走一条模拟轨迹，只更新轨迹上的状态：简单，但会反复打已经常去的状态，少见状态更新不足。

### 5.8 实时动态规划 RTDP

异步价值迭代 + 轨迹采样：只更新当前真实（或模拟）轨迹访问的状态。无关区域可以永远不碰。跑道问题（Racetrack）：状态是位置+速度，动作是加速度。随机策略下可达状态 9115，最优策略只用 599，更新次数大约减半。一定条件下以概率 1 收敛到最优。

### 5.9 决策时规划与启发式搜索

**背景规划（background planning）：** Dyna 那种，随时在脑子里备份，决策时只查表。  
**决策时规划（decision-time planning）：** 在当前 \(s\) 展开一棵树，搜完再选动作，动作结束后树可以扔（或部分复用）。

启发式搜索：根是当前状态，叶节点用已有 \(V\) 估价，再备份回根。单步贪心是深度 1 的退化。棋类程序、AlphaGo 的 MCTS 都是决策时规划。

### 5.10 蒙特卡洛树搜索（对照总结课件 AlphaGo）

MCTS 一轮四个步骤：

1. **选择：** 从根沿树策略走，常用 UCT
   \[
   \arg\max_a \left[ Q(s,a) + c \sqrt{\frac{\ln N(s)}{N(s,a)}} \right]
   \]
   这就是第 1 章 UCB 在树上的版本。
2. **扩展：** 把一个未见后继加入树。
3. **模拟（rollout）：** 从新节点用默认策略走到终止，得到回报。
4. **回传：** 把回报加到路径上每个 \((s,a)\) 的 \(N\) 和 \(Q\)。

AlphaGo：用策略网络缩小分支、用价值网络代替或辅助 rollout，再加人类棋谱行为克隆初始化。执行时 MCTS；训练时策略梯度 + 价值学习。第 9 章和总结课件会再提。

### 5.11 本章项目实战 P5：Dyna 迷宫与简易 MCTS

2. 实现优先级扫描，画“更新次数–误差”。
3. 在 Tic-Tac-Toe 或 4×4 迷宫实现 MCTS，比较纯 rollout 与带启发式 \(V\) 的叶估价。
4. 故意把模型学错（少记一堵墙），观察规划如何把错误传播到 Q，再对比 Dyna-Q+ 的修复。

## 第 6 章  函数近似、策略梯度与 Actor-Critic

> 对应课件：`6-近似逼近方法.pptx`（57 页），`7-1策略梯度方法.pdf`（CS285）  
> 教材：Sutton & Barto 第 9–13 章  
> 可视化：HTML 模块「策略梯度」

### 6.1 表格法的边界

表格型方法为每个 \(s\) 或 \((s,a)\) 存一个数。连续状态、图像、语言令牌都会让表爆炸。两条出路：

1. **离散化 / 分桶：** 把连续状态切成格子，或按先验特征聚类。简单，但维度灾难：每维切 \(m\) 段、\(d\) 维，格子数 \(m^d\)。边界处价值不连续。
2. **参数化函数近似：** \(v_w(s)\approx v_\pi(s)\)，\(q_w(s,a)\approx q_\pi(s,a)\)，\(\pi_\theta(a\mid s)\)。参数 \(w,\theta\) 的维度远小于 \(|\mathcal{S}|\)。

课件强调：RL 数据非稳态、非 i.i.d.，可微参数模型（线性、神经网络）比一次性建完的树模型更适合在线更新。

### 6.2 均方价值误差与 SGD

目标（在 on-policy 分布 \(d_\pi\) 下）：

\[
L(w) = \mathbb{E}_{s\sim d_\pi}\bigl[\bigl(v_\pi(s) - v_w(s)\bigr)^2\bigr]
\]

真实梯度

\[
\nabla_w L(w) = -2\,\mathbb{E}_{s\sim d_\pi}\bigl[\bigl(v_\pi(s)-v_w(s)\bigr)\nabla_w v_w(s)\bigr]
\]

随机梯度下降：抽到 \(s\)，若有无偏目标 \(U\approx v_\pi(s)\)，

\[
w \leftarrow w + \alpha\bigl(U - v_w(s)\bigr)\nabla_w v_w(s)
\]

- MC：\(U = G_t\)，无偏，收敛到 \(L(w)\) 的局部最优（线性时是全局）。
- TD：\(U = R_{t+1}+\gamma v_w(S_{t+1})\)，**半梯度**——对目标里的 \(w\) 不求梯度。线性 TD 在 on-policy 下仍收敛；非线性或 off-policy 时可能发散。

### 6.3 线性函数近似

\[
v_w(s) = w^\top x(s)
\]

\(x(s)\) 是特征（one-hot、tile coding、Fourier、径向基）。MC 更新：

\[
w \leftarrow w + \alpha\bigl(G_t - w^\top x(S_t)\bigr) x(S_t)
\]

TD(0)：

\[
w \leftarrow w + \alpha\,\delta_t\, x(S_t), \qquad
\delta_t = R_{t+1} + \gamma w^\top x(S_{t+1}) - w^\top x(S_t)
\]

线性 TD 的期望更新是 \(w_{k+1} = w_k + \alpha(b - A w_k)\)，其中

\[
A = \mathbb{E}\bigl[x(S_t)\bigl(x(S_t)-\gamma x(S_{t+1})\bigr)^\top\bigr], \quad
b = \mathbb{E}[R_{t+1}x(S_t)]
\]

on-policy 时 \(A\) 正定（严格对角占优意义下），收敛到 TD 不动点 \(w_{\mathrm{TD}} = A^{-1}b\)，它一般不是 \(L(w)\) 的最小点，而是投影 Bellman 方程的解。这是“TD 有偏”在函数近似里的精确含义。

动作价值同理：\(q_w(s,a)=w^\top x(s,a)\)，半梯度 SARSA / Q-learning 把 \(\delta\) 换成对应的 TD 误差。

### 6.4 基于策略的方法：为什么需要

课件第 35 页优缺点：

优点：

- 收敛性质更好（直接在策略空间上升，没有 \(\arg\max\) 的跳跃）。
- 高维或连续动作不必对 \(q\) 取 \(\max\)。
- 能学随机策略（对石头剪刀布、部分可观测、探索都必要）。

缺点：

- 通常局部最优。
- 策略评估效率低、梯度方差大。

### 6.5 目标函数与似然比技巧

有限视界目标 \(J(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}[R(\tau)]\)，\(R(\tau)=\sum_t \gamma^t r_t\)（CS285 也写无限视界平均）。轨迹密度

\[
p_\theta(\tau) = p(s_0)\prod_{t=0}^{T-1} \pi_\theta(a_t\mid s_t)\, p(s_{t+1}\mid s_t,a_t)
\]

直接微分：

\[
\nabla_\theta J(\theta)
= \nabla_\theta \int p_\theta(\tau) R(\tau)\, d\tau
= \int p_\theta(\tau)\, \nabla_\theta \log p_\theta(\tau)\, R(\tau)\, d\tau
\]

这就是 **log-derivative / likelihood-ratio 恒等式**：\(\nabla p = p \nabla\log p\)。而

\[
\nabla_\theta \log p_\theta(\tau)
= \sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t\mid s_t)
\]

环境 \(p(s'|s,a)\) 和 \(p(s_0)\) 消失。这是无模型策略梯度的关键：不需要动力学也能写梯度。于是

\[
\nabla_\theta J(\theta)
= \mathbb{E}_{\tau\sim\pi_\theta}\left[
  \left(\sum_{t=0}^{T-1} \nabla_\theta \log \pi_\theta(a_t\mid s_t)\right) R(\tau)
\right]
\]

直观（课件 + CS285）：好轨迹的 \(R\) 为正，增大这些 \((s,a)\) 的概率；坏轨迹减小概率。试错的形式化。

### 6.6 策略梯度定理（无限折扣，Sutton 第 13 章）

\[
\nabla_\theta J(\theta)
= \mathbb{E}_{s\sim d_{\pi_\theta},\, a\sim\pi_\theta}\bigl[
  \nabla_\theta \log \pi_\theta(a\mid s)\, q_{\pi_\theta}(s,a)
\bigr]
\]

**逐步证明。** 先对 \(v_\theta(s) := v_{\pi_\theta}(s)\) 求导。

\begin{align}
\nabla v_\theta(s)
&= \nabla \sum_a \pi_\theta(a\mid s) q_\theta(s,a) \\
&= \sum_a \bigl[\nabla\pi_\theta(a\mid s)\, q_\theta(s,a) + \pi_\theta(a\mid s)\nabla q_\theta(s,a)\bigr]
\end{align}

而 \(q_\theta(s,a)=r(s,a)+\gamma\sum_{s'}p(s'|s,a)v_\theta(s')\)，故 \(\nabla q_\theta(s,a)=\gamma\sum_{s'}p(s'|s,a)\nabla v_\theta(s')\)。代入并反复展开 \(\nabla v\)，得到

\[
\nabla v_\theta(s)
= \sum_{s'} \sum_{k=0}^{\infty} \gamma^k \Pr(s\to s', k, \pi_\theta)
\sum_a \nabla\pi_\theta(a\mid s')\, q_\theta(s',a)
\]

对 \(s\sim p_0\) 取期望，折扣访问测度吸进 \(d_{\pi_\theta}\)。再用 \(\nabla\pi = \pi \nabla\log\pi\) 即得定理。

单步 MDP（上下文老虎机）是特例：\(q(s,a)=r(s,a)\)，梯度退化为 \(\mathbb{E}[\nabla\log\pi(a|s)\, r]\)。

### 6.7 因果性：reward-to-go

未来动作不能影响过去奖励。把 \(R(\tau)\) 换成从 \(t\) 起的回报 \(G_t\)（reward-to-go）不改变期望、降低方差（CS285 Lecture）：

\[
\nabla J
= \mathbb{E}\left[\sum_t \nabla_\theta\log\pi_\theta(a_t\mid s_t)\, G_t\right]
\]

用 \(q_\pi(s_t,a_t)\) 或 \(A^\pi(s_t,a_t)\) 替换 \(G_t\) 同样无偏。

### 6.8 Baseline 无偏性

对任意只依赖状态的 \(b(s)\)，

\[
\mathbb{E}_{a\sim\pi_\theta(\cdot|s)}\bigl[\nabla_\theta\log\pi_\theta(a\mid s)\, b(s)\bigr]
= b(s)\nabla_\theta\sum_a \pi_\theta(a\mid s)
= b(s)\nabla_\theta 1 = 0
\]

所以减 baseline 不引入偏差。常用 \(b(s)=\hat{v}(s)\)，于是乘的是优势 \(A=q-v\)。平均回报也是合法但更粗的 baseline。CS285 指出最优 baseline 与梯度幅度加权的方差有关，实践中学一个 \(V_w\) 即可。

### 6.9 REINFORCE（蒙特卡洛策略梯度）

```
对每个片段 ~ π_θ:
  算所有 G_t
  对 t = 0..T-1:
    θ ← θ + α γ^t G_t ∇_θ log π_θ(A_t | S_t)
```

Softmax 策略（离散）：\(\pi(a|s)=\frac{e^{h(s,a)}}{\sum_{a'}e^{h(s,a')}}\)，\(\nabla\log\pi(a|s)= \nabla h(s,a)-\sum_{a'}\pi(a'|s)\nabla h(s,a')\)。  
高斯策略（连续）：\(a\sim\mathcal{N}(\mu_\theta(s),\sigma^2)\)，\(\nabla\log\pi = \frac{a-\mu}{\sigma^2}\nabla\mu\)。

课件 Puck World：连续小力推冰球靠近目标，目标每 30 秒重置，用 REINFORCE 训练。

### 6.10 Actor-Critic

Actor 更新策略，Critic 学 \(v_w\) 或 \(q_w\) 以提供低方差的优势。TD Actor-Critic：

\[
\delta_t = R_{t+1}+\gamma v_w(S_{t+1})-v_w(S_t)
\]
\[
w \leftarrow w + \alpha_w \delta_t \nabla_w v_w(S_t)
\]
\[
\theta \leftarrow \theta + \alpha_\theta \delta_t \nabla_\theta \log\pi_\theta(A_t\mid S_t)
\]

\(\delta_t\) 是 \(A^\pi(S_t,A_t)\) 的一步估计。A2C 用 n 步回报或 GAE 代替 \(\delta_t\)。

### 6.11 GAE（广义优势估计）

\[
\hat{A}_t^{\mathrm{GAE}(\gamma,\lambda)}
= \sum_{l=0}^{\infty}(\gamma\lambda)^l \delta_{t+l}
\]

\(\lambda=0\) 即 TD 优势 \(\delta_t\)；\(\lambda=1\) 即 MC 优势 \(G_t-V(s_t)\)。PPO / TRPO 默认几乎都用 GAE。这是 n 步 TD 在优势函数上的 \(\lambda\) 版本。

### 6.12 自动微分实现（CS285 伪代码）

监督学习：`loss = mean(cross_entropy(logits, actions))`。  
策略梯度：`loss = mean(cross_entropy(logits, actions) * q_values)`。

因为 \(\nabla_\theta \mathbb{E}[f \log\pi] = \mathbb{E}[f \nabla\log\pi]\)，把回报（或优势）当作不反传的权重乘在负对数似然上即可。**务必 `stop_gradient` 在优势上。** 这不是普通监督学习：梯度噪声大，batch 要更大，学习率更敏感，Adam 只是“还行”。

### 6.13 Off-policy 策略梯度与重要性采样

on-policy 梯度每个更新都要重新采样。神经网络每步只动一点点，数据利用率低。用行为策略 \(b\) 采样，

\[
\nabla J(\theta)
\approx \mathbb{E}_{\tau\sim b}\left[
  \rho_{0:T-1} \sum_t \nabla\log\pi_\theta(a_t|s_t) G_t
\right]
\]

若忽略状态分布差异、只保留单步比 \(\frac{\pi(a_t|s_t)}{b(a_t|s_t)}\)，就得到一阶近似，通向 off-policy Actor-Critic 和 PPO 的 ratio。课件 / CS285：忽略占用差后更像一次策略迭代。

### 6.14 致命三要素（为第 7 章铺路）

同时具备：函数近似 + 自助（bootstrapping）+ off-policy，表格型收敛保证消失，Q 可能发散。DQN 用经验回放（缓解相关）和目标网络（缓解自助的移动目标）做工程上的压制，不是理论上取消三要素。

## 第 7 章  深度强化学习：价值方法

> 对应课件：`7-深度强化学习价值方法.pptx`（38 页）  
> 论文：Mnih et al., Nature 2015；van Hasselt et al., AAAI 2016；Wang et al., ICML 2016；Schaul et al., ICLR 2016  
> 可视化：HTML 模块「DQN」

### 7.1 深度 RL 的分类（课件）

- 基于价值：DQN 及其扩展。
- 基于随机策略：神经网络策略梯度、自然梯度、TRPO、PPO、A3C。
- 基于确定性策略：DPG、DDPG。

本章只做价值。回顾表格 Q-learning：\(Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]\)，“此处无梯度”。深度时 \(Q\) 变成 \(Q_\theta(s,a)\)，损失是 TD 误差平方，用 SGD 反传。

### 7.2 朴素 DQN 为何不稳

两件事同时坏：

1. **样本相关：** 连续帧高度相关，SGD 假设被破坏。
2. **移动目标：** 目标 \(y=r+\gamma\max_{a'}Q_\theta(s',a')\) 与在线网络共享 \(\theta\)，更新 \(Q\) 时目标跟着跑，像用一张会动的标签做回归。

再加上回报尺度变化、稀疏奖励、探索不足，训练极易发散或遗忘。

### 7.3 经验回放

把转移 \((s,a,r,s',\mathrm{done})\) 放入有限 replay buffer，训练时均匀随机抽 mini-batch。作用：

- 打破时间相关，近似 i.i.d.。
- 同一条经验被多次使用，提高样本效率。
- 平滑数据分布，避免只拟合当前策略的局部轨迹。

这使 DQN 成为 **off-policy** 方法：行为策略（\(\varepsilon\)-greedy 的当前 \(Q\)）与被更新的目标可以不同。

**优先经验回放（PER，Schaul ICLR 2016）。** 按 \(|\delta_i|^\omega\) 抽样，并用不偏修正权重 \(w_i = (N P(i))^{-\beta}\)。TD 误差大的转移更常被学。\(\beta\) 从某值退火到 1，以恢复无偏。

### 7.4 目标网络

复制一份 \(\theta^-\leftarrow\theta\)，若干步（或软更新）才同步一次。目标

\[
y = r + \gamma \max_{a'} Q_{\theta^-}(s', a') \quad (\text{若 } s'\text{ 终止则 } y=r)
\]

损失

\[
L(\theta) = \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}\bigl[\bigl(y - Q_\theta(s,a)\bigr)^2\bigr]
\]

\(y\) 对 \(\theta\) 视为常数。评估网络每步更新，目标网络“冻住”提供缓慢移动的回归标签。课件：目标网络是评估网络几轮前的拷贝。

Nature DQN 在 Atari 上相对职业人类测试员归一化，许多游戏达到或超过人类水平（课件第 20 页）。

### 7.5 算法流程（对照 Nature 2015）

```
初始化 replay D，θ，θ^- ← θ
for episode:
  重置环境，预处理 φ1 = φ(s1)
  for t:
    以 ε 随机，否则 a_t = argmax_a Q_θ(φ_t, a)
    执行 a_t，得到 r_t, s_{t+1}，φ_{t+1}=φ(s_{t+1})
    存 (φ_t, a_t, r_t, φ_{t+1}) 到 D
    从 D 抽 batch，算 y_i（终止则 r，否则 r+γ max Q_{θ^-}）
    梯度下降 (y_i - Q_θ(φ_i,a_i))^2
    每 C 步 θ^- ← θ
```

Atari 预处理：灰度、84×84、跳帧、把最近 4 帧叠成状态，奖励裁剪到 \(\{-1,0,1\}\)。

### 7.6 过估计与 Double DQN

\(\max_{a'} Q(s',a')\) 在 \(Q\) 有噪声时是上偏的：\(\mathbb{E}[\max_a (q_a+\epsilon_a)] \ge \max_a q_a\)。候选动作越多，过估计越严重（van Hasselt NIPS 2010 / AAAI 2016）。过估计会通过 Bellman 备份传播，形成虚假的“高价值区域”。

Double Q-learning 把 **选动作** 和 **估价值** 解耦：

\[
y = r + \gamma Q_{\theta^-}\bigl(s', \arg\max_{a'} Q_\theta(s', a')\bigr)
\]

在线网络选 \(a^*\)，目标网络给 \(Q(s',a^*)\)。课件实验：价值估计误差下降，Atari 分数上升。

### 7.7 Dueling DQN

分解

\[
Q(s,a) = V(s) + A(s,a)
\]

若无约束，\(V\) 与 \(A\) 不可辨识（加上常数、减去常数，\(Q\) 不变）。实践用

\[
Q(s,a) = V(s) + \Bigl(A(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'}A(s,a')\Bigr)
\]

或减 \(\max_{a'}A(s,a')\)。优点（课件）：

- 许多状态的价值与具体动作关系不大，\(V\) 可以被所有动作的数据更新。
- Advantage 只在“动作真正造成差别”时发力（例如正前方有车才强调刹车）。
- 走廊环境里“不动”动作很多，Dueling 的 Q 估计 MSE 更低。

Saliency map 显示网络把注意力放在关键像素上。

### 7.8 其它常用扩展（总结课件也列了）

- **n 步 DQN：** 目标换成 n 步回报，偏差方差再折中。
- **NoisyNet：** 参数噪声探索，替代退火 \(\varepsilon\)。
- **Distributional RL（C51 / QR-DQN）：** 学回报分布而非期望。
- **Rainbow：** 把 Double、Dueling、PER、n 步、Distributional、Noisy 集成。

工程上先把 Nature DQN 跑稳，再加 Double 和 Dueling，比一上来 Rainbow 更有利于理解。

### 7.9 本章项目实战 P7：DQN 打 CartPole / LunarLander

1. 从零实现 replay buffer、\(\varepsilon\) 退火、目标网络硬更新。
2. 消融：无 replay、无目标网络、两者都有。无 replay 通常明显不稳。
3. 实现 Double DQN，比较平均 Q 值是否更小（是否抑制过估计）。
4. 实现 Dueling 头，比较样本效率。
5. 选做：PER；或上 Atari Pong（计算量大，可用 1 千万帧以下的小实验）。

**验收标准。** CartPole-v1 在合理超参下 100 局平均 ≥ 475；能画出 Q 均值曲线并解释 Double 的差异。

## 第 8 章  深度强化学习：策略方法

> 对应课件：`8-深度强化学习策略方法.pptx`（52 页）  
> 论文：Silver ICML 2014 DPG；Lillicrap ICLR 2016 DDPG；Mnih NIPS 2016 A3C；Schulman ICML 2015 TRPO；Schulman 2017 PPO  
> 可视化：HTML 模块「PPO Clip」

### 8.1 随机策略与确定性策略

| | 离散动作 | 连续动作 |
|---|---|---|
| 随机 \(\pi(a|s)\) | softmax，可微 | 高斯，可微 |
| 确定性 \(\mu(s)\) | 不可微（argmax） | 可微（若 \(\mu\) 可微） |

连续动作上，确定性策略可把梯度从 \(Q\) 经 \(a=\mu(s)\) 反传到 \(\theta\)，不必在动作维采样。这是 DPG / DDPG 的出发点。

### 8.2 确定性策略梯度（DPG）

目标 \(J(\mu_\theta)=\mathbb{E}_{s\sim d^\mu}[q^\mu(s, \mu_\theta(s))]\)。Silver et al. 证明

\[
\nabla_\theta J(\mu_\theta)
= \mathbb{E}_{s\sim d^\mu}\bigl[
  \nabla_\theta \mu_\theta(s)\; \nabla_a q^\mu(s,a)\big|_{a=\mu_\theta(s)}
\bigr]
\]

链式法则：策略改动作，动作经 critic 的 \(\partial Q/\partial a\) 告诉你这个方向好不好。off-policy 版本用行为策略的占用替换 \(d^\mu\)，critic 用 Q-learning 学。课件对比 COPDAC-Q、SAC（此处指随机 Actor-Critic）、OffPAC-TD。

### 8.3 DDPG

把 DPG 接到深度网络（Lillicrap et al.）：

- Actor \(\mu_\theta(s)\)，Critic \(Q_w(s,a)\)。
- 两边都有目标网络，**软更新** \(\theta^- \leftarrow \tau\theta + (1-\tau)\theta^-\)。
- 探索：在动作上加噪声（Ornstein–Uhlenbeck 或高斯），所以是 off-policy。
- Critic 损失：\(y = r + \gamma Q_{w^-}(s', \mu_{\theta^-}(s'))\)。
- Actor 损失：\(-Q_w(s, \mu_\theta(s))\)（上升 \(J\)）。

课件实验：目标网络至关重要；批归一化有帮助；甚至像素输入也能工作。后续 TD3 修了 DDPG 的过估计（双 critic 取 min、延迟更新 actor、目标动作加噪声）。SAC 则回到随机策略并加熵项。

### 8.4 A2C / A3C

A2C：优势 Actor-Critic，同步并行环境收集数据。  
A3C（Mnih NIPS 2016）：多个 worker 异步各自与环境交互、算梯度、推到全局网络。课件强调：16 CPU 无 GPU 即可在 57 个 Atari 上得到与当时 GPU DQN 可比的人类归一化分数。异步本身提供探索多样性，也打破数据相关，因此 A3C 往往不用 replay。

### 8.5 策略梯度的步长灾难

REINFORCE / 普通 AC 在参数空间走一步 \(\theta\leftarrow\theta+\alpha\nabla\hat{J}\)。策略空间与参数空间不是等距的：同样 \(\|\Delta\theta\|\)，有的方向 KL 很大，策略崩溃，下一轮数据全坏，再也爬不回来。课件：“一步踩空掉到山下”。这就是性能坍塌（总结课件第 15 页）。

### 8.6 TRPO：可信域

性能差的精确恒等式（Kakade / Schulman）：

\[
J(\pi') - J(\pi)
= \frac{1}{1-\gamma}\mathbb{E}_{s\sim d_{\pi'}, a\sim\pi'}\bigl[A^\pi(s,a)\bigr]
\]

\(d_{\pi'}\) 不能用 \(\pi\) 的数据直接采样。用 \(d_\pi\) 代替并重要性采样，得到替代目标

\[
L_\pi(\pi') = J(\pi) + \frac{1}{1-\gamma}\mathbb{E}_{s\sim d_\pi, a\sim\pi}\left[
  \frac{\pi'(a|s)}{\pi(a|s)} A^\pi(s,a)
\right]
\]

Schulman 证明：若 \(\max_s \mathrm{KL}(\pi(\cdot|s)\|\pi'(\cdot|s))\le \delta\)，则 \(J(\pi')\) 与 \(L_\pi(\pi')\) 的差距有界，从而 **单调改进** 可保证（课件“策略改进的单调性保证”）。实践约束平均 KL：

\[
\max_\theta\; \mathbb{E}\left[\frac{\pi_\theta(a|s)}{\pi_{\mathrm{old}}(a|s)}\hat{A}\right]
\quad\mathrm{s.t.}\quad
\mathbb{E}\bigl[\mathrm{KL}(\pi_{\mathrm{old}}\|\pi_\theta)\bigr] \le \delta
\]

用共轭梯度解 Fisher-vector 积，再 line search。细节见《动手学强化学习》11.4。TRPO 的不足：近似误差、约束优化难做、实现重。

### 8.7 PPO：用 clip 构造下界

PPO-Clip 目标（Schulman 2017）：

\[
L^{\mathrm{CLIP}}(\theta)
= \mathbb{E}_t\left[
  \min\bigl(
    r_t(\theta)\hat{A}_t,\;
    \mathrm{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t
  \bigr)
\right]
\]

其中 \(r_t(\theta)=\frac{\pi_\theta(a_t|s_t)}{\pi_{\mathrm{old}}(a_t|s_t)}\)。

**为什么是下界。** 若 \(\hat{A}>0\)，想提高 \(r\)；clip 把 \(r\) 上限卡在 \(1+\epsilon\)，\(\min\) 取未裁与已裁中的较小者，不会为了极端增大 \(r\) 而走太远。若 \(\hat{A}<0\)，想降低 \(r\)；clip 下限 \(1-\epsilon\)，\(\min\)（注意负数）阻止 \(r\) 过小。于是 \(L^{\mathrm{CLIP}}\le L^{\mathrm{CPI}}\) 在“超出信任域”的方向上更保守。

PPO-Penalty：把 KL 当自适应惩罚，系数按 KL 大于/小于目标的 1.5 倍调整（课件：1.5 与 2 是经验值，不敏感）。

实践默认：PPO-Clip + GAE + 多 epoch mini-batch，是目前最常用的深度 on-policy 算法（课件总结原句）。

### 8.8 PPO 实现要点（项目会用到）

1. 收集 \(N\) 步 on-policy 数据后，才更新 \(K\) 个 epoch；下一轮必须重采。
2. Advantage 标准化。
3. 价值损失 \(c_v (V_\theta(s)-G_t)^2\)，熵奖励 \(c_e \mathcal{H}(\pi(\cdot|s))\)。
4. 连续动作：对角高斯，\(\log\sigma\) 常与状态无关或有界。
5. KL 超标可 early stop。
6. 不要把旧策略的 logprob 用新网络重算当 old——old 必须存下来。

### 8.9 本章项目实战 P8：PPO 连续控制

1. 在 Pendulum-v1 或 Hopper（若有 MuJoCo / 免费替代）实现 PPO-Clip。
2. 画出 \(r_t(\theta)\) 的直方图，确认大部分落在 \([1-\epsilon,1+\epsilon]\)。
3. 对比 \(\epsilon=0.1,0.2,0.5\)：过大是否坍塌。
4. 去掉 clip 变成普通策略梯度多 epoch，复现“一步踩空”。
5. 选做：DDPG 于 Pendulum，感受 off-policy 样本效率 vs 调参脆弱。

## 第 9 章  基于模型的深度强化学习

> 对应课件：`9-基于模型的深度强化学习.pptx`（30 页）  
> 论文：Chua et al. NIPS 2018 PETS；Janner et al. NeurIPS 2019 MBPO

### 9.1 用模型替换真实环境

真实交互贵（机器人损坏、推荐系统伤用户、自动驾驶危险）。用 \(\hat{p}_\phi(s',r|s,a)\) 生成模拟数据，在模拟里规划或训练策略。第 5 章 Dyna 已是这个思想；本章把它接到深度网络、短视界 MPC、以及“何时该信模型”。

### 9.2 模型预测控制 MPC

不学 \(\pi\) 或 \(V\)，每一步：

1. 从当前 \(s_t\) 用模型打出多条长度为 \(H\) 的动作序列。
2. 评估累积奖励，挑最好的一条。
3. **只执行该序列的第一个动作**，然后根据真实观测重规划。

这叫滚动时域。模型错了还有机会用真实反馈纠正，所以短 \(H\) 往往比开环执行整条计划更稳。

**随机打靶：** 动作序列从简单分布（如均匀或高斯）抽。  
**CEM（交叉熵方法）：** 维护动作序列分布 \(q(\mathbf{a})\)；每次抽一批，用精英样本（高回报）重新拟合 \(q\)，迭代后均值挤向好计划。

### 9.3 PETS

Probabilistic Ensembles with Trajectory Sampling（Chua et al.）：

- 集成 \(B\) 个神经网络，每个输出高斯 \(p(s'|s,a)=\mathcal{N}(\mu_\phi(s,a), \Sigma_\phi(s,a))\)。
- **偶然不确定（aleatoric）：** 单模型的 \(\Sigma\)，环境固有随机。
- **认知不确定（epistemic）：** 各成员在数据稀处预测不一致。
- 轨迹采样：每步可从集成中抽一个成员推进粒子（TS1 / TS∞ 等变体）。
- 规划用 CEM + 粒子平均回报。

少量真实试验即可在部分 MuJoCo 任务上接近无模型方法的渐近性能，样本效率高。

### 9.4 模型误差如何毁策略

多步展开时误差复合（compounding error）。策略在模型里看起来很好，真实环境里可能很差。Janner et al. 把策略价值误差拆成：

- 模型泛化误差：\(\hat{p}\) 与 \(p\) 在 **当前数据分布** 上的差。
- 策略偏移：新策略走到模型没见过的区域，误差被放大。

课件：更多使用模型推演 → 样本效率更高，但价值误差界随推演深度 \(k\) 变差。因此 **短分支** 优于从 \(s_0\) 开环滚到结束。

### 9.5 MBPO

Model-Based Policy Optimization：

1. 用真实数据训练动力学集成。
2. 从真实 replay 里抽状态当分支起点（不是总从 \(s_0\)）。
3. 用模型推演 \(k\) 步（\(k\) 可随训练增大，但保持很小，如 1–7）。
4. 把推演数据丢进独立 buffer，用 SAC 训练策略。

这是 Dyna 的深度版：真实数据练模型，短模拟练策略，策略是无模型算法（SAC）。课件实验环境：Gym / MuJoCo 机器人。

### 9.6 本章项目实战 P9：MPC 与极简 MBPO

1. 在 Pendulum 上拟合线性或小 MLP 动力学，用随机打靶 / CEM 做 MPC，比较视界 \(H=5,15,40\)。
2. 画多步预测误差随 \(H\) 增长的曲线，亲眼看 compounding error。
3. 选做：2 步分支 + SAC 的玩具 MBPO，对比纯 SAC 的样本效率。
4. 把模型训练不足时硬推演 50 步，展示策略在模型里满分、真环境里崩溃。

### 9.7 本章自测

## 第 10 章  模仿学习

> 对应课件大纲第 10 章（简介课件第 43–44 页；材料中无独立 ppt，按课程大纲与 HRL / CS285 补全）  
> 关键词：BC、DAgger、IRL、GAIL

### 10.1 何时模仿而不是强化学习

奖励难设计、交互危险、但有专家示范（人类驾驶、棋谱、操作演示）时，可直接学专家策略。Waymo 收购 Latent Logic 等工业案例说明：仿真 + 模仿是自动驾驶的常规组合。

### 10.2 行为克隆 BC

把示范 \(\{(s_i, a_i)\}\) 当监督学习：

\[
\theta^* = \arg\min_\theta \sum_i \ell\bigl(\pi_\theta(s_i), a_i\bigr)
\]

离散动作用交叉熵，连续用 MSE 或负对数似然。实现最简单，但有 **协变量偏移**：专家轨迹只覆盖专家占用 \(d_{\pi_E}\)；学习者一旦偏离，会到达没有示范的状态，错误复合。这与第 9 章 compounding error 同构。

### 10.3 DAgger

Dataset Aggregation（Ross et al.）：

1. 用当前 \(\pi_\theta\) 与环境交互得到状态。
2. 请专家在这些状态上标注动作。
3. 把新数据并入训练集，再 BC。

学习者的占用被逐步纳入训练集，偏移被压下去。代价是需要在线专家。

### 10.4 从示范反推奖励：IRL / GAIL

逆强化学习假设专家近似最优，求 \(r\) 使专家在该 \(r\) 下最优。GAIL 用生成对抗：策略是生成器，判别器区分专家与学习者占用，策略用 TRPO/PPO 最大化“骗过判别器”的奖励。AIRL 进一步得到可迁移奖励。

### 10.5 与 RL 的结合

AlphaGo：先 BC 初始化策略网络，再 RL 自我对弈。许多机器人工作：BC 热启动 + PPO 微调。离线 RL（第 11 章）可看成“在固定示范/日志上做比 BC 更远的改进”，但必须处理 OOD。

### 10.6 本章项目实战 P10：CartPole 模仿

1. 用已经训好的 DQN / PPO 当专家，采集 20 / 100 / 500 条轨迹。
2. BC 学策略，测成功率随示范数量变化。
3. 实现一轮简化 DAgger（用专家策略当 oracle 标注）。
4. 比较 BC 与“在同一批数据上做 CQL / 离线 SAC”的回报——引出下一章。

### 10.7 本章自测

1. BC 的协变量偏移从哪一步产生？
2. DAgger 如何改变训练状态分布？
3. GAIL 的奖励从哪来？它还是强化学习吗？
4. 为何 AlphaGo 不满足于纯 BC？

## 第 11 章  离线强化学习

> 对应课件：`11-离线强化学习.pptx`（22 页）  
> 论文：Levine et al. arXiv:2005.01643；Fujimoto ICML 2019 BCQ；Kumar NeurIPS 2020 CQL

### 11.1 设定

训练期 **禁止** 与环境交互，只能用固定数据集 \(\mathcal{D}=\{(s,a,r,s')\}\)。测时再下环境。动机：自动驾驶、医疗、机器人、推荐系统从零试错不可接受。离线 RL 让 RL 更像监督学习：有训练集、有测试环境。

和 off-policy 的差别（课件第 6 页）：off-policy 仍可交互，只是行为策略与目标策略不同；离线完全不能交互，不能靠探索修正错误 Q。

### 11.2 外延误差

数据集由行为策略 \(\pi_\beta\) 产生，占用 \(\rho_{\pi_\beta}\)。学习策略 \(\pi\) 的占用一旦离开 \(\mathrm{supp}(\mathcal{D})\)，\(Q(s,a)\) 被神经网络乱外推，\(\max_a Q(s,a)\) 会选 OOD 动作并乐观高估。TD 备份把该错误传到数据集内部的 Q，整张表被污染。这就是 extrapolation error。

即便是 off-policy 深度算法（DQN/DDPG），在纯离线时也会失败（课件 BCQ 页：“甚至离线策略学习方法也会失效”）。

### 11.3 方法地图

无模型 + 显式约束：BCQ、BEAR、BRAC、CQL。  
无模型 + 隐式约束：AWR、REM、BAIL。  
基于模型：MOReL、MOPO、COMBO（用不确定性或保守惩罚限制推演）。

评测：RL Unplugged、D4RL、NeoRL。

### 11.4 BCQ

表格思想：目标只在数据集支撑上取 max，

\[
y = r + \gamma \max_{a':\, (s',a')\in\mathrm{supp}(\mathcal{D})} Q(s', a')
\]

连续动作：用 VAE 生成靠近数据集的动作，再在生成动作的小扰动里选 Q 最大者。Actor 近似模仿 \(\pi_\beta\)，Critic 在模仿动作邻域里做受限 Q-learning。课件提到乐观与保守之间的平衡。

### 11.5 CQL

Conservative Q-Learning（Kumar et al.）：在 Bellman 误差之外， **压低** 策略分布下的 Q、 **抬高** 数据分布下的 Q：

\[
\min_Q \quad
\alpha\Bigl(
  \mathbb{E}_{s\sim\mathcal{D}, a\sim\pi}[Q(s,a)]
  - \mathbb{E}_{(s,a)\sim\mathcal{D}}[Q(s,a)]
\Bigr)
+ \tfrac12 \mathbb{E}_{\mathcal{D}}\bigl[(Q-\mathcal{B}^\pi \bar Q)^2\bigr]
\]

效果：OOD 动作的 Q 被主动打低，\(\arg\max Q\) 不敢离开数据。课件实验：多种 Gym 与数据设置下 CQL 常常最好。

直觉：普通 Q-learning 对未见 \((s,a)\) 没有惩罚，拟合误差向上或向下都可能；最大化策略会利用向上的误差。CQL 把“向上的误差”变成训练目标里的正项，梯度会把它推下去。

### 11.6 实践要点

- 先报告 BC 基线。离线 RL 若不超过 BC，没有说服力。
- 数据质量（expert / medium / random）比算法名字更影响上限。
- 标准化回报、保守系数 \(\alpha\)、是否 twin Q，都敏感。
- 用 FQE 或在线回滚做评估时声明清楚，不要用训练 Q 当性能。

### 11.7 本章项目实战 P11：离线 CartPole

## 第 12 章  参数化动作空间

> 对应课件：`12-参数化行动空间.pptx`（23 页）  
> 论文：Masson et al. AAAI 2016；Hausknecht & Stone ICLR 2016；Xiong et al. 2017 P-DQN

### 12.1 离散、连续、混合

- 离散：从有限集合选一个。像分类。不能对已选动作做微调。
- 连续：输出实向量。像回归。不能表达“种类不同”的互斥技能。
- **参数化动作：** 先选离散类型，再为该类型输出连续参数。例子：
  - 足球：冲刺(方向, 速度)、转向(方向)、踢球(方向, 力度)、停止。
  - 游戏手柄：离散按键 + 连续摇杆。
  - MOBA / RTS、带时限的交易下单、机器人“抓 / 推 / 放”加力与目标位姿。

形式：动作 \(a = (k, x_k)\)，\(k\in\{1,\ldots,K\}\)，\(x_k\in\mathcal{X}_k\subseteq\mathbb{R}^{d_k}\)。这是 PAMDP（Parameterized Action MDP）。动作选择是分层的，结构本身是有用信息。

### 12.2 三条算法路线

1. **离散化连续参数：** 把 \(x_k\) 切成格子，变成大离散空间，用 DQN。简单，精度差，维度灾难。
2. **把离散动作放宽成连续：** 输出每个 \(k\) 的连续分数再加参数，用 DDPG 一类（Hausknecht & Stone）。执行时对离散维取 argmax。
3. **分开处理：** 用 DQN 选 \(k\)，用 DDPG 式头输出 \(x_k\)。这是 P-DQN。

### 12.3 Q-PAMDP

交替：固定参数策略，把问题看成离散 MDP 做 Q-learning；再固定离散选择，优化连续参数。Masson et al. 给出收敛讨论：内层离散 MDP 的最优与外层参数改进交替，类似坐标上升。

### 12.4 P-DQN

对每个离散 \(k\) 定义 \(Q(s, k, x_k)\)。网络：

- 参数头：\(x_k = \mu_k(s)\)（确定性）。
- 价值头：\(Q(s, k, x_k)\)。

选动作：\(k^* = \arg\max_k Q(s, k, \mu_k(s))\)，执行 \((k^*, \mu_{k^*}(s))\)。更新：离散侧像 DQN，连续侧像 DDPG 对 \(x_k\) 反传 \(\nabla_x Q\)。课件实验含简单实例与 RoboCup HFO（半场进攻）：低级连续状态 + 参数化连续动作，指标包括平均奖励、进球百分比、回合长度。

### 12.5 本章项目实战 P12：玩具足球 PAMDP

设计 2D 场地：动作集合 {移动(角度,步长), 射门(角度,力度), 停}。奖励：进球 +1，出界 -0.1，每步 -0.01。

1. 离散化基线（DQN）。
2. P-DQN 或“softmax 选 k + 高斯参数”的 PPO 混合策略。
3. 比较进球率与动作使用直方图（是否学会在禁区才射门）。

## 第 13 章  目标导向的强化学习

> 对应课件：`13-目标导向的强化学习.pptx`（9 页）  
> 论文：Schaul ICML 2015 UVFA；Andrychowicz NIPS 2017 HER；Liu et al. IJCAI 2022 综述

### 13.1 问题

标准 RL 学的是 **一个** 任务：固定地图、固定终点。换终点就要重训。复杂任务（多房间取物、机械臂连续抓取、先拿钥匙再开门）需要把长期任务拆成子目标。

Goal-oriented / Goal-conditioned RL：把目标 \(g\) 显式喂给策略和价值，测试时给新 \(g\) 直接泛化。

### 13.2 建模

增广状态 \((s,g)\)。奖励通常稀疏：

\[
r(s,a,s',g) = \begin{cases}
0 & \text{若 } \|s'-g\| < \delta \\
-1 & \text{否则}
\end{cases}
\]

目标仍是最大化期望累积奖励，但现在条件于 \(g\)。Universal Value Function Approximators（UVFA）：

\[
v_w(s, g) \approx v^\pi(s, g), \qquad
\pi_\theta(a \mid s, g)
\]

\(g\) 可以是目标状态、语言指令、图像。

### 13.3 稀疏奖励与 HER

训练初期几乎碰不到 \(g\)，全是 \(-1\)，什么都学不会。Hindsight Experience Replay 的观察：一条“失败”轨迹虽然没到预定 \(g\)，但它 **确实到达了轨迹上的某些状态** \(s'\)。把该转移的目标 **重标注** 为实际到达的状态，这条经验立刻变成正样本。

算法（可接 DQN / DDPG / PPO）：

```
存整条轨迹 τ = (s0,a0,...,sT)
对每个转移，除了原 g，再采样未来状态 s' 作为 g'
奖励按 g' 重算
把 (s,a,r',s',g') 放入 replay
```

策略：final（用片段末状态）、future（用之后随机状态，最常用）、episode、random。课件 2D 到达点实验：带 HER 的 DDPG 能学，不带 HER 几乎不能。

HER 不是改环境，是改 **对经验的解释**：任何轨迹都是“到达它所到之处”的专家。这与后见之明（hindsight）的日常含义一致。

### 13.4 层次与子目标

长视界、复合模型误差、稀疏反馈（简介课件第 41 页）可用子目标把任务切短。Hierarchical Foresight（Nair & Finn ICLR 2020）在视觉空间生成中间状态。UVFA + HER 是平坦目标条件；层次 RL（HIRO、HAC）在上层输出 \(g\)，下层执行。

### 13.5 本章项目实战 P13：BitFlip 与 2D Reach

1. 实现 BitFlipping：状态是 n 位比特，动作翻转一位，目标是随机目标比特串。n=15 时无 HER 的 DQN 几乎失败，有 HER 可成功。这是 HER 原论文的教学实验。
2. 实现课件 2D 世界：位置连续，动作是位移，距离小于阈值给 0 否则 -1，最长 50 步。比较 DDPG vs DDPG+HER。
3. 画“重标注前后的成功标签比例”，理解 HER 如何制造正样本。

## 第 14 章  多智能体强化学习

> 对应课件：`14-多智能体强化学习.pptx`（40 页）及英文版  
> 论文：Hu & Wellman JMLR 2003 Nash-Q；Lowe et al. MADDPG；综述 CTDE

### 14.1 非稳态：核心困难

从单个智能体看，其它智能体是环境的一部分。但其它智能体也在学习，转移核

\[
p(s'\mid s, a^i) = \sum_{a^{-i}} \pi^{-i}(a^{-i}\mid s)\, p(s'\mid s, a^i, a^{-i})
\]

随 \(\pi^{-i}\) 改变而改变。单智能体 Q-learning 的收敛前提（环境稳态）被破坏。课件原句：把其它智能体当环境再用独立 Q 学习，会破坏理论保证，使学习不稳定。

例子：MAgent 大规模战斗与队形；StarCraft 微操通信；CityFlow 交通灯与路由；仓储分拣机器人布局。

### 14.2 三种序贯决策（博弈论）

| 问题 | 智能体数 | 状态 |
|---|---|---|
| MDP | 1 | 多个 |
| 重复博弈 | 多个 | 1 个 |
| 随机博弈 / 马尔可夫博弈 | 多个 | 多个 |

完全可观测的 MARL 属于随机博弈：每个状态一张博弈表，全体同时选动作，得到各自奖励，按联合动作转移到下一状态。折扣累积各自的回报。

随机博弈元组：\((\mathcal{S}, \mathcal{A}^1,\ldots,\mathcal{A}^n, p, r^1,\ldots,r^n, \gamma)\)。合作：共享 \(r\)；竞争：零和；一般和：各自 \(r^i\)。

### 14.3 完全中心化

把全体当成一个超级智能体，联合动作 \(a=(a^1,\ldots,a^n)\)。环境变回稳态 MDP。缺点：

- 联合动作空间指数爆炸。
- 无法处理真正的对抗（“超级智能体”假设可协调所有人）。
- 执行时往往也要求全局通信。

**Nash-Q：** 每个状态解一般和博弈的 Nash 均衡，用均衡值当 bootstrap，而不是 \(\max\)。计算贵，均衡不唯一时理论麻烦，课件也指出难以处理某些非合作场景。

Nash 的含义：没有任何智能体单独改变策略能提高自己的价值。学习目标从“最优策略”变成“均衡策略”。

### 14.4 完全去中心化（独立学习）

每个智能体跑独立 PPO / DQN，把别人当环境。实现简单，可处理局部观测。缺点：非稳态，可能不收敛。课件 Combat 格子对战：独立 PPO 对内置脚本有一定胜率，但不稳定。

独立学习在同质大量智能体、奖励共享、对手变化慢时有时能用，不能当理论安全网。

### 14.5 CTDE

Centralized Training with Decentralized Execution：训练时用全局信息（全体观测、联合动作）训 critic；执行时每个 actor 只看自己的观测。

MADDPG：每个智能体一个 DDPG actor；critic 输入 \((x, a^1,\ldots,a^n)\)，\(x\) 为全局。因为 critic 看见联合动作，在训练视角下环境重新变“稳态”（给定全体动作）。执行不需要别人的动作。

其它 CTDE：COMA（反事实优势）、QMIX（单调混合全局 Q）、MAPPO（PPO 的中心化价值）。合作任务里 QMIX / MAPPO 很常用；混合动机用 MADDPG 更自然。

### 14.6 本章项目实战 P14：简单追逃与合作通信

1. 实现 2 智能体格子追逃：独立 Q vs MADDPG 式中心化 critic。
2. 合作通信玩具：只有一个智能体看见目标颜色，必须发离散消息，另一个才能选对门（参考 OpenAI particle env 的思路，可自写简化版）。
3. 记录“对手策略冻结 / 同时学习”两种协议下的曲线，观察非稳态。

## 第 15 章  强化学习前沿与大模型

> 对应课件：`强化学习前沿.pptx`（21 页）；大纲第 15 章“强化学习大模型”

### 15.1 关键挑战清单（课件第 4 页）

1. 样本效率低 → 依赖仿真 → sim2real gap。
2. 训练不稳、超参敏感；函数近似死亡三角；策略坍塌。
3. 奖励设计与奖励黑客（reward hacking）。
4. 任务泛化。
5. 探索–利用。
6. 多智能体。

下面按课件结构给出每个挑战对应的技术方向，以及你应当掌握的 **问题意识**（不必在本课程内全部实现）。

### 15.2 样本效率：仿真、离线、世界模型

- **仿真：** 先在模拟器里学。必须面对 sim2real：领域随机化、系统辨识、迁移学习。
- **离线 RL：** 第 11 章。用日志预训练，再小量上线微调。
- **世界模型：** 学 \(p(o_{t+1}, r_t \mid h_t, a_t)\)，在想象中训练策略。循环世界模型（RSSM / Dreamer）、空间智能、视频生成式世界、可交互物理世界，是课件列出的演进。决策时在世界模型里做 MPC 或策略优化，回到第 5、9 章。

### 15.3 超参敏感：更好的算法与“像监督学习那样做”

- 单调改进：TRPO / PPO（第 8 章）。
- 自动算法发现（元学习 RL 算法）。
- 把 RL 改成序列建模：Decision Transformer 把 \((R,s,a)\) 当条件语言模型，用回报条件做“上到下”生成，避免 TD 不稳。
- 扩散模型生成整条轨迹。
- 行为克隆依赖大量专家 → 人工数据合成。

Decision Transformer 的核心式：把目标回报 \(R\) 当提示，模型输出动作。它不是 Bellman 备份，因此没有自助过估计，但泛化依赖数据覆盖，离线设定下与 CQL 竞争。

### 15.4 奖励：RLHF

Reinforcement Learning from Human Feedback：用人类（或 AI）偏好数据学奖励模型 \(r_\phi\)，再对语言模型做 PPO / 其它 RL 微调。这是大模型对齐的主流之一。注意奖励黑客：模型可以找到 \(r_\phi\) 的漏洞（讨好、冗长、表面安全）。课件把 RLHF 放在“奖励函数设计”下，强调奖励仍然是瓶颈。

RLHF 的 PPO 目标与第 8 章相同，只是 \(r_t\) 来自奖励模型，并常加 KL 惩罚，防止远离 SFT 策略：

\[
r_t^{\mathrm{used}} = r_\phi(s_t, a_t) - \beta \,\mathrm{KL}\bigl(\pi_\theta(\cdot|s_t)\|\pi_{\mathrm{SFT}}(\cdot|s_t)\bigr)
\]

这又是一次信任域思想。

### 15.5 泛化：通用智能体、LLM+RL、VLA

- 通用智能体：同一套权重做多任务（RT-1、Gato 等思路）。
- LLM+RL：语言作为策略或规划接口，RL 微调推理链（数学推理、工具使用）。
- VLA（Vision-Language-Action）：OpenVLA 一类，视觉–语言–动作端到端。把机器人策略当成多模态序列模型。

### 15.6 应用地图（课件第 21 页）

游戏 AI；机器人与自动驾驶；金融量化 FinRL；军事对抗；芯片布局 / 交通信号 / 工业控制 / 物流；医疗；对话、谈判、导购；数学推理；算法发现（AlphaDev）。选应用时先问：状态是什么、动作是否安全可试、奖励能否定义、有没有模拟器或日志。

### 15.7 本章项目实战 P15：小世界模型或微型 RLHF

二选一（工作量控制在一周）：

**A. 世界模型玩具。** 在 CartPole 上学一个 MLP 动力学，冻结后在想象中用 CEM 控制，比较真实环境回报。分析 30 步后预测发散。

## 第 16 章  总结回顾：两条主线如何收束

> 对应课件：`总结回顾.pptx`（25 页）

### 16.1 一张图记住全课

```
                ┌─ 有模型 ─ DP / Dyna / MPC / PETS / MBPO / MCTS
  预测 v 或 q  ─┤
                └─ 无模型 ─ MC / TD / n-step / GAE
                         │
                         ▼
                   GPI：评估 + 改进
                         │
         ┌───────────────┴───────────────┐
     值方法（改进=对 Q 贪心）     策略梯度（改进=沿 ∇J 上升）
     SARSA, Q-learning            REINFORCE, A2C
     DQN, Double, Dueling         DPG, DDPG
                                  TRPO, PPO, SAC
```

再往外加约束与结构：离线（CQL/BCQ）、目标条件（HER）、混合动作（P-DQN）、多智能体（CTDE）、人类反馈（RLHF）。

### 16.2 值方法要点复盘

如何算值函数？Bellman 方程。表格用备份，深度用 TD 损失 + 目标网络。控制用 SARSA（on-policy）或 Q-learning（off-policy）。探索：\(\varepsilon\)-greedy 或 Boltzmann softmax。连续动作：DDPG / TD3 / SAC。稳定性：Double、PER、n 步、熵正则、GAE。

### 16.3 策略梯度要点复盘

如何算策略梯度？回报加权的最大似然（log-trick）。减 baseline / 用优势降方差。性能坍塌来自参数空间一步过大。TRPO 用 KL 信任域；PPO 用 ratio clip 做实用下界。确定性策略把 \(\nabla_a Q\) 链式回传到 actor。分布式 AC 用 CPU 采样、GPU 更新。

### 16.4 AlphaGo 作为综合题

训练：BC 初始化 → 策略梯度自我对弈 → 价值网络评估。  
执行：策略先验 + 价值叶子 + MCTS（决策时规划）。  
它把第 5、7、8、9、10 章焊在同一个系统里。能用本课语言把 AlphaGo 讲顺，说明基础段和深度段已经接通。

### 16.5 习题 14：火箭回收的奖励设计

题目：若用 RL 做 SpaceX 式回收，如何设计奖励以保证平稳落地？

不要只给“落地 +100”。建议分层、稠密、安全约束：

1. **主任务：** 落地成功（速度、姿态、位置同时进入阈值）给大正奖励；坠毁大负。
2. **稠密塑形：** \(-\|x-x_{\mathrm{pad}}\| - \lambda_v \|v\| - \lambda_\omega \|\omega\| - \lambda_\theta |\theta|\)，引导飞向塔台并减速、扶正。
3. **燃油：** \(-\lambda_f \cdot \mathrm{throttle}\)，避免为了姿态猛喷导致无燃料。
4. **约束惩罚：** 超过过载、撞地倾角过大、落在区外，用大负或提前终止。
5. **平滑：** 惩罚动作二阶差分，减少抖动（也利于 sim2real）。
6. **课程：** 先高空悬停，再平移，再完整回收；或先稠密奖励再退火到稀疏成功奖励，防止奖励黑客（围着塑形项盘旋不落地）。

塑形必须 **与最优策略一致**：不能让“在空中刷塑形分”比落地更合算。这是 Ng 等人关于 reward shaping 的势函数条件在工程上的提醒。

## 附录 A  课程习题逐步解答

题目来源：`习题.docx`。以下按题目顺序给出推导，数字题给出计算过程。

### A.1 用奖励表示 \(V\) 和 \(Q\)，以及它们的含义

\[
v_\pi(s)=\mathbb{E}_\pi\!\left[\sum_{k=0}^{\infty}\gamma^k R_{t+k+1}\mid S_t=s\right]
\]
\[
q_\pi(s,a)=\mathbb{E}_\pi\!\left[\sum_{k=0}^{\infty}\gamma^k R_{t+k+1}\mid S_t=s,A_t=a\right]
\]

\(v_\pi(s)\)：从状态 \(s\) 出发遵循 \(\pi\) 的长期好坏。  
\(q_\pi(s,a)\)：在 \(s\) 先执行 \(a\) 再遵循 \(\pi\) 的长期好坏。

### A.2 \(V\) 关于 \(Q\)，\(Q\) 关于 \(V\)

\[
v_\pi(s)=\sum_a \pi(a\mid s) q_\pi(s,a)
\]
\[
q_\pi(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s')
\]

确定性策略时 \(v_\pi(s)=q_\pi(s,\pi(s))\)。

### A.3 Bellman 期望方程（递归）

把 A.2 两式互代，或由 \(G_t=R_{t+1}+\gamma G_{t+1}\) 取期望：

\[
v_\pi(s)=\sum_a\pi(a\mid s)\Bigl[r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)v_\pi(s')\Bigr]
\]
\[
q_\pi(s,a)=r(s,a)+\gamma\sum_{s'}p(s'\mid s,a)\sum_{a'}\pi(a'\mid s')q_\pi(s',a')
\]

最优方程把求和 \(\sum_a\pi\) 换成 \(\max_a\)。详见第 2.7–2.8 节逐步展开。

### A.4 强化学习与有监督学习的区别

数据是否 i.i.d.、反馈是否即时标签、是否改变数据过程、有无探索、目标是拟合还是累积奖励。展开见第 2.15 节表格。

### A.5 值函数估计的两种主方法及偏差方差

蒙特卡洛：无偏（first-visit）、高方差。  
时序差分：有偏（依赖当前 \(V\)）、低方差。  
详见第 3.5 节。

### A.6–A.7 Q 表贪心动作

给定

| \(Q\) | \(a_0\) | \(a_1\) | \(a_2\) |
|---|---|---|---|
| \(s_0\) | 1.0 | 0.3 | 2.2 |
| \(s_1\) | -0.3 | 0 | -1.5 |
| \(s_2\) | 3.0 | 2.0 | -2.0 |

贪婪：\(s_0\) 选 \(a_2\)，\(s_1\) 选 \(a_1\)，\(s_2\) 选 \(a_0\)。  
\(\varepsilon\)-greedy：以 \(1-\varepsilon\) 选上述动作，以 \(\varepsilon\) 在 \(\{a_0,a_1,a_2\}\) 均匀随机。

### A.8 DP、TD、MC 的区别

DP：完全备份，要模型，无采样方差。  
TD：一步采样 + 自助，无模型，有偏低方差，可在线、可持续任务。  
MC：采样到终止，无模型，无偏高方差，必须片段式。  
备份深度：DP/TD 浅，MC 深，n 步居中。

### A.9 SARSA 与 Q-learning 更新

\[
\text{SARSA: } Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)]
\]
\[
\text{Q-learning: } Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]
\]

### A.10 TD(\(n\)) 与 \(n\) 的影响

\[
G_{t:t+n}=\sum_{k=1}^{n}\gamma^{k-1}R_{t+k}+\gamma^n V(S_{t+n})
\]

（控制时 \(V(S_{t+n})\) 换成 \(Q(S_{t+n},A_{t+n})\) 或 \(\max_a Q\)。）  
\(n=1\)：偏差大、方差小、归责近。  
\(n\to\infty\)：偏差小、方差大、归责远。  
实践在中间取最佳 \(n\) 或用 \(\lambda\) 混合。

### A.11 Dyna 为何加快收敛

真实一步之外，用模型对已访问 \((s,a)\) 做额外备份，相当于同一条经验在脑子里重放多次，价值沿可能路径传播得更快。规划次数 \(n\) 越大（模型足够准时）越快。见第 5.5 节。

### A.12 Off-policy 的优点

可用探索策略收集数据同时学最优策略；可复用旧经验、人类数据、其它智能体数据；一个行为策略可评估多个目标策略；是经验回放与离线 RL 的前提。见第 4.3 节。

### A.13 轨迹上的 MC 与 2 步 TD 目标

设初始 \(Q\equiv 0\)，折扣 \(\gamma\)，轨迹到 \(T\) 终止。对时刻 \(t=0\)：

1. MC 目标：\(G_0=\sum_{k=0}^{T-1}\gamma^k R_{k+1}\)。与 \(Q\) 无关。
2. \(N=2\) 的 TD 目标：\(G_{0:2}=R_1+\gamma R_2+\gamma^2 Q(S_2,A_2)\)。初始 \(Q=0\) 时第三项为 0，故 \(G_{0:2}=R_1+\gamma R_2\)。

若题目给出具体 \((R_1,R_2,\ldots)\) 与 \(\gamma\)，代入即得数字。注意终止状态的 \(Q\) 恒为 0。

### A.14 火箭回收奖励

见第 16.5 节完整设计：成功稀疏项 + 位置/速度/姿态稠密塑形 + 燃油与过载约束 + 动作平滑 + 课程学习，并检查塑形不可被黑客。

## 附录 E  核心公式速查（默写纸）

交互：\(s_t, a_t\sim\pi,\; r_{t+1}, s_{t+1}\sim p\)。

回报：\(G_t=R_{t+1}+\gamma G_{t+1}\)。

Bellman 期望：\(v_\pi=\mathcal{T}^\pi v_\pi\)，\(q_\pi\) 同。

Bellman 最优：\(v_*=\mathcal{T} v_*\)。

TD(0)：\(\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t)\)。

SARSA：\(Q\leftarrow Q+\alpha[R+\gamma Q(S',A')-Q]\)。

Q-learning：\(Q\leftarrow Q+\alpha[R+\gamma\max_{a'}Q(S',a')-Q]\)。

n 步：\(G_{t:t+n}=\sum_{k=1}^n\gamma^{k-1}R_{t+k}+\gamma^n V(S_{t+n})\)。

策略梯度：\(\nabla J=\mathbb{E}[\nabla\log\pi(a|s)\, q_\pi(s,a)]\)。

带 baseline：\(\nabla J=\mathbb{E}[\nabla\log\pi(a|s)\, A^\pi(s,a)]\)。

GAE：\(\hat{A}_t=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}\)。

DPG：\(\nabla J=\mathbb{E}[\nabla_\theta\mu_\theta(s)\,\nabla_a Q(s,a)|_{a=\mu(s)}]\)。

DQN 目标：\(y=R+\gamma\max_{a'}Q_{\theta^-}(S',a')\)。

Double：\(y=R+\gamma Q_{\theta^-}(S',\arg\max_a Q_\theta(S',a))\)。

PPO：\(L=\mathbb{E}[\min(r\hat{A},\mathrm{clip}(r,1-\epsilon,1+\epsilon)\hat{A})]\)。

UCB1：\(Q(a)+c\sqrt{(\ln t)/N(a)}\)。

UCT：\(Q(s,a)+c\sqrt{(\ln N(s))/N(s,a)}\)。

CQL 惩罚：\(\mathbb{E}_{\pi}[Q]-\mathbb{E}_{\mathcal{D}}[Q]\)。

HER：失败轨迹用实际到达状态当 \(g'\) 重算奖励。

## 附录 G  常见误区（改作业时对照）

1. 把 \(R_t\) 写成与 \(A_t\) 同时发生。本课程约定奖励是 \(R_{t+1}\)。
2. 用 \(v\) 做无模型贪心。无模型贪心必须用 \(q\)。
3. 认为 Q-learning 是 on-policy，因为行为是 \(\varepsilon\)-greedy。学的目标是 \(\max\)，所以是 off-policy。
4. 把 greedy 执行回报当成 Q-learning 的训练曲线。悬崖例子训练时行为仍 \(\varepsilon\)-greedy。
5. TD 目标里对 \(V(S_{t+1})\) 求梯度。半梯度不求。
6. PPO 把新旧数据混进一个无限 replay。破坏 on-policy。
7. DQN 在 `done=True` 时仍 bootstrap。必须 \(y=r\)。
8. 重要性采样漏掉覆盖假设，行为策略对某动作概率为 0。
9. 离线实验不报 BC。
10. HER 去改环境奖励函数，而不是改 buffer 里的 \(g\)。
11. 独立 Q 学习当 MARL 的默认“正确算法”。
12. 奖励塑形后不检查是否可被黑客。
13. 单种子曲线当结论。
14. \(\gamma=1\) 用于平均每步为正的无限视界任务，期望无穷。
15. 把 occupancy measure 当成“访问次数的直方图就行”，忘记折扣与 \((1-\gamma)\) 归一化。
