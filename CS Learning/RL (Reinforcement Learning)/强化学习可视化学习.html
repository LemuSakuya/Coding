格子世界里的价值迭代

4×4 迷宫，每步 −1，右下角终止。价值迭代反复应用 Bellman 最优算子 \(\mathcal{T}\)。颜色越亮表示价值越高（越靠近终点）。箭头是贪心策略。

vk+1(s) = maxa [ r(s,a) + γ Σs' p(s'|s,a) vk(s') ]　　‖𝒯u − 𝒯w‖∞ ≤ γ ‖u−w‖∞
0.90 k = 0
观察 k=0 全是 0。第一次迭代只有终点旁边变成 −1。价值从终点向外渗，这就是课件策略评估那几页的数字过程。
γ 变大：远处格子也值得走（更有远见）。γ 变小：策略变得短视。

悬崖漫步：SARSA vs Q-learning

掉下悬崖 −100 并回起点。Q-learning 学最优动作价值，路径贴着悬崖（短但危险）。SARSA 学 ε-greedy 自己的价值，主动远离。这是 on-policy / off-policy 最清楚的画面。

SARSA: Q(s,a) ← Q + α[r + γQ(s',a')]　　Q-learning: Q ← Q + α[r + γ maxa' Q(s',a')]

DQN：经验回放 + 目标网络

连续样本相关、TD 目标跟着在线网络跑，是朴素深度 Q 不稳的两个原因。Replay 随机打乱；目标网络 θ⁻ 缓慢复制 θ，把回归标签冻住一会儿。

y = r + γ maxa' Qθ⁻(s',a')　　Double: y = r + γ Qθ⁻(s', argmaxa Qθ(s',a))

每步把 (s,a,r,s') 放入环状缓冲。缓冲足够后随机抽一批算 TD 损失。每隔 C 步把 θ 复制到 θ⁻。

PPO Clip：不要一步踩空

普通策略梯度在参数空间走太远，策略崩溃，下一轮数据全坏。PPO 用重要性比值 r(θ) 的截断，构造替代目标的保守下界。

HER：失败轨迹也是「到达它所到之处」的专家

目标条件 RL 的奖励常常稀疏，碰不到 g 就全是 −1。事后经验回放把目标改成轨迹实际到达的状态，失败立刻变成正样本。

多智能体：别人一学，你的环境就非稳态

单智能体视角下 p(s'|s,ai) 还依赖其他人的策略。对方策略在变，你的 Q 学习收敛前提就没了。CTDE 用中心化 critic 在训练时看见联合动作，执行时 actor 仍只看自己。

石头—剪刀—布式循环随时可能出现
完全中心化：联合动作，环境稳态，动作空间爆炸。
独立学习：实现简单，非稳态，可能不收敛。
CTDE：训练看全局，执行看局部。MADDPG / QMIX / MAPPO。
