# 06 串口通信 UART

## 1. UART 基本参数

- 波特率：常用 9600 / 115200
- 数据位：一般 8 位
- 停止位：1 位
- 校验位：可无（8N1 为最简配置）

## 2. 51 单片机串口配置要点

### 2.1 寄存器设置

- **SCON**：配置工作模式（Mode 1 = 0x50，8 位 UART，允许接收）
- **TMOD**：T1 设为 Mode 2（8 位自动重装）
- **TH1 / TL1**：根据目标波特率计算初值
- **TI / RI**：发送/接收完成标志位，需软件清零
- **ES / EA**：若使用中断接收，必须开启串口中断和总中断

### 2.2 波特率计算（11.0592MHz 晶振）

```
TH1 = 256 − (11,059,200 / (12 × 32 × 9600))
    = 256 − 3
    = 253
    = 0xFD
```

误差 0%：11.0592MHz 是专门为产生标准波特率设计的晶振频率。

## 3. 发送与接收代码模板

### 3.1 发送（轮询方式）

```c
void uart_send(uchar dat)
{
    SBUF = dat;
    while (!TI);   // 等待发送完成
    TI = 0;        // 清除标志
}
```

### 3.2 接收（中断方式）

```c
void uart_isr(void) interrupt 4
{
    if (RI) {
        RI = 0;
        // 处理 SBUF 中的数据
    }
}
```

接收推荐使用中断方式，避免主循环因 `while (!RI)` 被阻塞。

## 4. 调试建议

- 使用 USB 转串口模块（CH340 / CP2102）连接实物
- Proteus 中使用 Virtual Terminal 监控串口数据
- 发送**可打印 ASCII 字符**（`'0'`~`'9'` 而非 0x00~0x09），否则 Virtual Terminal 不会显示
- 串口助手先确认收发参数一致再排查协议逻辑

## 5. 双机通信实验（课程实验六）

### 5.1 实验任务

使用两片 AT89C51 完成单向串口通信：

- **乙机（发送端）**：按键触发，依次发送 `'0'` `'1'` `'2'` `'3'` `'4'`（循环），P3.0 LED 指示发送状态
- **甲机（接收端）**：中断接收，查表驱动共阴数码管显示对应数字

### 5.2 系统框图

```
┌─────────────────┐        ┌─────────────────┐
│   乙机（发送端）  │  TXD   │   甲机（接收端）  │
│                 │────────→│                 │
│ P1.7 ← 按键      │  P3.1   │ P3.0(RXD)       │
│ P3.0 → TX LED   │        │ P0  → 数码管段选  │
│ P3.1 → TXD      │        │                 │
└─────────────────┘        └─────────────────┘
         │                          │
         └────── GND 共地 ──────────┘
```

### 5.3 硬件连接表

| 信号 | 甲机引脚 | 乙机引脚 | 说明 |
|------|---------|---------|------|
| 段选 | P0.0~P0.7 | — | 共阴数码管 a~g, dp |
| RXD | P3.0 | — | 串行接收 |
| TXD | — | P3.1 | 串行发送 |
| 按键 | — | P1.7 | 低电平有效，外接上拉 |
| TX LED | — | P3.0 | 发送指示灯，低电平亮 |
| GND | GND | GND | **必须共地** |

### 5.4 常见故障排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 数码管不亮 | P0 开漏无上拉 | 在 P0 加 10kΩ 排阻上拉到 VCC |
| 数码管不亮 | 共阳/共阴极搞反 | 共阳需加 `~` 取反段码值 |
| Virtual Terminal 无显示 | 发送了不可打印字符 | 发送 `'0'+index` 而非 `index` |
| 接收到乱码 | 波特率不匹配 | 确认双方晶振 11.0592MHz，TH1=0xFD |
| 按键一次发多个 | 消抖不足 | 增大 delay_ms 或加释放等待 |
| 完全无反应 | 未共地 | 检查两片单片机 GND 连接 |
| LED 不亮 | 极性接反 | P3.0 低电平有效：阳极→电阻→VCC，阴极→P3.0 |
