# 实验 07：LCD1602 电子时钟

> 对应扩展任务：使用定时器、LCD1602 和 3 个按键，设计完成 24 小时制电子时钟。

## 一、实验目标

1. 掌握 LCD1602 的 8 位并行显示接口
2. 使用定时器 T0 产生 1 秒计时节拍
3. 实现 24 小时制电子时钟显示
4. 使用 3 个按键完成小时调节、分钟调节和时钟清零

## 二、硬件连接约定

- 单片机：AT89C51 / AT89C52
- 晶振：12MHz
- LCD：LM016L / LCD1602
- LCD 数据口：`P3.0~P3.7 -> D0~D7`
- LCD 控制口：
  - `P2.0 -> RS`
  - `P2.1 -> RW`
  - `P2.2 -> E`
- 按键：
  - `P1.0 -> K1`，小时加 1
  - `P1.1 -> K2`，分钟加 1
  - `P1.2 -> K3`，时钟清零并重新开始计时

按键采用低电平有效：按键一端接 I/O 口，另一端接 GND。

## 三、显示效果

LCD 第一行显示：

```text
  H.I.T. CHINA
```

LCD 第二行显示：

```text
TIME  00:00:00
```

## 四、程序思路

1. LCD1602 初始化为 8 位数据、2 行显示、光标关闭
2. T0 设置为方式 1，50ms 中断一次
3. 软件计数 20 次中断得到 1 秒
4. 秒满 60 后分钟加 1，分钟满 60 后小时加 1，小时满 24 后归 0
5. 主循环扫描 3 个按键，并在时间变化后刷新 LCD

## 五、关键参数

12MHz 晶振下，51 单片机机器周期为 1us。

50ms 需要计数 50000 次：

```text
65536 - 50000 = 15536 = 0x3CB0
```

所以 T0 初值为：

```c
TH0 = 0x3c;
TL0 = 0xb0;
```

## 六、运行步骤

1. 在 Keil 新建 C51 工程，选择 AT89C51 或 AT89C52
2. 添加 `main.c`
3. 编译生成 `.hex`
4. 在 Proteus 中按上面的端口连接 LCD1602 和 3 个按键
5. 双击单片机加载 `.hex`，晶振频率设置为 12MHz
6. 运行仿真，观察 LCD 时间变化并测试三个按键

## 七、报告建议

1. 实验任务：24 小时制电子时钟，带小时调节、分钟调节和清零功能
2. 电路原理：LCD1602 数据线、控制线、按键低电平输入、定时器计时
3. 程序流程：初始化 LCD、初始化 T0、定时中断计秒、主循环扫描按键
4. 调试现象：LCD 显示 `TIME  00:00:00` 并每秒递增
5. 问题总结：LCD 数据口要与程序一致，按键需要消抖，定时器中断不能直接执行大量 LCD 操作
