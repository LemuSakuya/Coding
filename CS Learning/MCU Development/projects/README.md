# 单片机开发项目清单

## 01_key_led_flow

按键控制流水灯实验（与你当前课程作业匹配）：
- K1：8 路 LED 正向流水
- K2：8 路 LED 反向流水
- K3：高 4 位 / 低 4 位交替闪烁
- K4：8 路 LED 全闪
- K5（扩展）：LED0&7 -> LED1&6 -> LED2&5 -> LED3&4 循环

## 02_timer_interrupt_counter

定时器中断实验：
- 定时器 T0 1ms 中断
- 软件计数得到 1 秒节拍
- LED 每 1 秒翻转一次

## 03_seven_segment_display

数码管显示实验（对应课程作业中的实验二）：
- 静态显示：单个数码管循环显示 0~9
- 动态显示：4 位数码管动态扫描显示 0000~9999
- 可配置共阳/共阴电平极性，便于在 Proteus 中快速适配

## 05_countdown_timer

30 秒倒计时实验：
- T0 方式 1 定时，12MHz 晶振下 50ms 中断一次
- 两次中断得到 0.1s，数码管从 30.0 倒计时到 0.0
- P3.7 按键控制开始、暂停、复位

## 07_lcd1602_digital_clock

LCD1602 电子时钟实验：
- T0 方式 1 定时，12MHz 晶振下 50ms 中断一次
- 软件计数得到 1 秒节拍，显示 24 小时制时间
- 3 个按键分别实现小时加 1、分钟加 1、时钟清零重新计时

## 说明

每个项目目录均包含：
- README.md：实验要求、连线说明、运行步骤
- main.c：可直接放入 Keil C51 工程的参考代码
