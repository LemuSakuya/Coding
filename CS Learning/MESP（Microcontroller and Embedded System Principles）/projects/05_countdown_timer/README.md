# 实验 05：30 秒倒计时

> 目录中的实验报告模板写的是“实验4”，但参考程序内容是 30S 倒计时实验。

## 一、实验目标

1. 掌握 51 单片机定时器 T0 的方式 1 使用方法
2. 用定时器中断实现 0.1s 节拍
3. 用三个 7 段数码管显示 `30.0` 到 `0.0`
4. 用 P3.7 按键实现开始、暂停、复位

## 二、硬件连接约定

- 单片机：AT89C51 / AT89C52
- 晶振：12MHz
- 按键：P3.7，按下为低电平
- 数码管：共阴极
- 百位/十位/个位段码分别接到 P0、P2、P1

显示含义：

- `P0` 显示十秒位
- `P2` 显示秒个位，并点亮小数点
- `P1` 显示 0.1 秒位

例如初始值 `second = 300`，显示为 `30.0`。

## 三、程序思路

1. `second` 保存倒计时值，单位是 0.1 秒
2. T0 工作在 16 位定时器模式，50ms 进入一次中断
3. 中断计数 `timer` 到 2，正好经过 100ms，`second--`
4. 每次 `second--` 后刷新三个数码管
5. P3.7 按键每按一次切换状态：
   - 第 1 次：开始倒计时
   - 第 2 次：暂停
   - 第 3 次：复位到 `30.0`

## 四、关键参数

12MHz 晶振下，51 单片机机器周期为 1us。

50ms 需要计数 50000 次：

```text
65536 - 50000 = 15536 = 0x3CB0
```

所以：

```c
TH0 = 0x3c;
TL0 = 0xb0;
```

## 五、运行步骤

1. 在 Keil 新建 C51 工程
2. 选择 AT89C51 或 AT89C52
3. 添加 `main.c`
4. 编译生成 `.hex`
5. 在 Proteus 中按上面的端口连接并加载 `.hex`
6. 运行仿真，按 P3.7 测试开始、暂停、复位

## 六、报告建议

报告可以按这个顺序写：

1. 实验目的：定时器、中断、数码管显示、按键控制
2. 实验原理：T0 方式 1、50ms 中断、两次中断得到 0.1s
3. 硬件电路：单片机、三个数码管、P3.7 按键
4. 程序流程：初始化、按键状态切换、中断倒计时、刷新显示
5. 调试结果：初始显示 `30.0`，开始后递减，到 `0.0` 自动停止
6. 问题总结：按键需要等待松手，定时器中断中要重装初值
