# 实验 06：甲乙双机串口通信

> 对应课程作业里的双机通信实验。

## 一、实验目标

1. 理解 51 单片机 UART 串口通信原理（模式 1，8 位异步）
2. 掌握波特率计算方法（11.0592MHz → 9600 bps）
3. 甲机通过串口中断接收数据，并查表驱动数码管显示
4. 乙机通过按键触发发送，实现单向数据通信

## 二、系统框图

```
┌─────────────────────┐        ┌─────────────────────┐
│       乙机（发送端）  │  TXD   │       甲机（接收端）  │
│                     │────────→│                     │
│  P1.7 ← 按键        │  P3.1  │  P3.0(RXD)          │
│  P3.1 → TXD         │        │  P0 → 数码管段选     │
└─────────────────────┘        └─────────────────────┘
          │                              │
          └──────── GND 共地 ────────────┘
```

## 三、硬件连接约定

| 信号 | 甲机引脚 | 乙机引脚 | 说明 |
|------|---------|---------|------|
| 段选 | P0.0~P0.7 | — | 数码管 a~g, dp |
| RXD | P3.0 | — | 串行接收 |
| TXD | — | P3.1 | 串行发送 |
| 按键 | — | P1.7 | 低电平有效，外接上拉 |
| GND | GND | GND | 必须共地 |

- 单片机型号：AT89C51 / AT89C52
- 晶振：11.0592MHz（两组相同）
- 数码管：共阴极（段码高电平亮）

## 四、功能说明

### 乙机（发送端）— `乙机.c`

1. 上电后初始化串口（9600 bps）
2. 循环检测 P1.7 按键
3. 按键按下（低电平）：
   - 软件消抖 10ms
   - 发送当前序号（首次为 0）
   - 序号 +1，若超过 4 则回到 0
   - 等待按键释放（防止连发）

### 甲机（接收端）— `甲机.c`

1. 上电后初始化串口（9600 bps），数码管显示 0
2. 串口中断接收数据：
   - 读取 SBUF 中的字符
   - 若字符值 > 4 则视为非法，按 0 处理
   - 查段码表输出到 P0 驱动数码管

## 五、波特率计算

晶振 11.0592MHz，UART 模式 1，T1 模式 2（8 位自动重装）：

```
TH1 = 256 − (11,059,200 / (12 × 32 × 9600))
    = 256 − 3
    = 253
    = 0xFD
```

误差：0%（11.0592MHz 是专门为产生标准波特率设计的）

## 六、运行步骤

1. 在 Keil 中分别创建两个工程：
   - 工程 A：加入 `甲机.c`，编译生成 `甲机.hex`
   - 工程 B：加入 `乙机.c`，编译生成 `乙机.hex`
2. 在 Proteus 中放置两片 AT89C51：
   - 甲机：连接数码管到 P0，TXD 悬空（仅接收）
   - 乙机：P1.7 接按键到 GND（上拉电阻），TXD 接甲机 RXD
   - **两机 GND 必须相连**
3. 分别加载 `.hex` 文件
4. 运行仿真，按下乙机按键观察甲机数码管变化

## 七、验收要点

| 序号 | 验收项 | 预期现象 |
|------|--------|---------|
| 1 | 按键→发送 | 每按一次 P1.7，乙机 TXD 有波形输出 |
| 2 | 串口接收 | 甲机 RI 置位，SBUF 收到正确字符 |
| 3 | 数码管显示 | 按下按键，数字 0→1→2→3→4→0 循环 |
| 4 | 循环发送 | 发完 4 后再按回到 0，不会跳到 5 |
| 5 | 防抖处理 | 一次按键只发一个字符，不连发 |

## 八、故障排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 甲机数码管不亮 | 段选极性反了 | 将 `seg_table` 值取反，或换共阳极管 |
| 接收到乱码 | 波特率不匹配 | 确认双方晶振均为 11.0592MHz，TH1=0xFD |
| 按键一次发多个字符 | 消抖不足 | 增大 `delay_ms` 参数 |
| 完全无反应 | 未共地 | 检查两片单片机 GND 是否连接 |
| 显示数字与按键次数不对 | 中断未开启 | 检查 EA=1, ES=1 |
