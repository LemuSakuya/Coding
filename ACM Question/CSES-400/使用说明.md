# 怎么使用这份参考资料

[返回总目录](README.md)

## 查一道题

1. 在 [中文思路总览](中文思路总览.md) 搜索题号或题名，例如 `1069` 或 `Repetitions`。
2. 先看中文思路、复杂度、易错点，尝试自己补全实现。
3. 打开该题资料，再打开 `reference.cpp` 对照完整代码。少数题还附第二种实现或高精度 Python 版本。
4. 需要更长的推导时，查看该题的“作者详细英文解析”链接。若有原文订正提示，先阅读提示。
5. 不能从样例通过推出完全正确；还需要检查边界、复杂度和整数范围。

中文说明是每题的参考解法速查，部分与参考程序采用不同的数据结构。比如可以用树状数组解决的计数问题，某份程序可能使用线段树或有序统计树。先比较状态与不变量是否等价，不必要求实现逐行相同。

## 对答案时比较什么

### 唯一输出

例如计数、最小费用、最长长度等，通常可以忽略空格与换行的差异，比较输出项。但你的思路与参考答案都只通过样例，仍不能证明算法正确。

对于 `long long`，注意不仅接收结果的变量需要 64 位，计算乘法时也必须使用 64 位操作数。例如 `long long ans = n * (n + 1) / 2;` 若 `n` 是 `int`，右边仍可能先发生 32 位溢出，可改为 `1LL * n * (n + 1) / 2`。

### 多解与构造题

输出与样例、参考代码不同，经常是合法的。应检查：

- 排列：是否恰好包含全部需要的数，各一次；是否满足所有相邻或位置限制。
- 路径：端点正确，相邻位置有边，是否要求最短、访问全部点、每条边仅用一次等。
- 匹配或分组：是否覆盖足够对象，是否重复使用对象，是否达到目标数量或最优值。
- 染色：是否满足相邻异色，是否必须改变每个格子的原色，使用颜色数是否最少。
- 操作序列：逐步模拟后的结果是否合法，是否超过操作次数限制。

例如 Weird Algorithm 要输出唯一的一整条序列；Two Sets 可以有很多组合法答案；Longest Common Subsequence 也可能有多条同长度答案。

### 浮点与近似答案

应按原题规定的绝对或相对误差比较数值。输出 `3.500000` 与 `3.5` 是同一个数；接近四舍五入边界的期望题还可能需要更高精度，合集保留作者提供的额外 Python 文件。

### 交互题

6 道交互题需要与评测器进行双向通信。它们没有普通的静态样例输入输出，也不能把参考程序作为一次性读入题运行。询问语法、次数限制、输出刷新及评测器错误回复，都是解法的一部分。

## 几个很容易混淆的题

|题目|关键区别|
|---|---|
|Coin Combinations I / II|I 区分顺序，II 不区分；循环顺序决定计数对象。|
|Subarray Sums I / II|I 的正数条件允许滑动窗口；II 含负数，需要前缀和计数。|
|Increasing Array / II|前者只增加，后者可增可减，算法不同。|
|Substring Order I / II|I 每种内容只算一次；II 按出现次数重复计入。|
|Filled / Border Subgrid|前者内部全部同色；后者只要求四条边同色。|
|Subgrid Count I / II|请逐题核对是正方形还是任意长方形。|
|Course Schedule / II|II 按课程编号依次尽早完成，不等价于正向最小堆的最小字典序拓扑序。|
|Sliding Window Sum / Minimum 等生成器题|部分输出所有窗口结果的 XOR；其他题逐窗口输出，不能统一套格式。|
|Missing Coin Sum / Queries|前者排序后一次贪心，后者每个询问针对不同原下标区间。|

## 不熟悉术语时先看这里

- **前缀和**：把从开头到每个位置的和提前算好，任意区间和就能用两个前缀相减。
- **滑动窗口 / 双指针**：一段连续区间的两个端点只向前移动；利用条件的单调性避免重复搜索。
- **贪心**：每一步选一个局部最优方案。需要说明为何可以把任意最优解交换成这样的选择。
- **DP（动态规划）**：先明确状态具体表示什么，再按最后一步或新加入的对象分类，把大问题转成已解决的小问题。
- **单调栈**：栈内的值保持递增或递减，常用来找左右第一个更大、更小值；每个元素通常只进出一次。
- **树状数组（BIT）**：支持单点增量和前缀统计；常与离散化配合，处理比当前数更小的元素数量。
- **线段树**：把数组分成一棵区间树，维护和、最值等信息。合并区间时必须保留足够描述左右关系的数据。
- **懒标记**：区间整体更新时先在节点记录待下传的操作，真正访问孩子时再处理。
- **并查集（DSU）**：维护哪些对象属于同一组，适合连通性与最小生成树；带权版还能记录到组代表的数值差。
- **BFS**：按步数层次搜索，适合每条边代价相同的最短路。
- **Dijkstra**：以当前最短距离为优先级扩展，适合非负边权最短路。
- **SCC（强连通分量）**：一组有向图顶点彼此可达；缩成一个点后得到 DAG。
- **DAG**：没有有向环的图，可按拓扑序处理 DP。
- **LCA**：树上两点最近公共祖先，可用于路径距离、差分与倍增查询。
- **倍增**：预处理走 1、2、4、8…步后的结果，再按二进制组合大步数。
- **树链剖分**：把树上的一条路径拆成少量数组区间，以复用线段树等结构。
- **点分治**：选择树的重心，把所有经过重心的路径单独计算，再递归处理剩余子树。
- **线性基**：用二进制消元保留互相独立的异或向量，用于子集异或最值、数量与排名。
- **SOS DP**：高效汇总每个二进制掩码的全部子掩码或超掩码信息。
- **KMP / Z 函数**：利用已知前缀匹配信息快速比较字符串，避免每个起点重新逐字匹配。
- **后缀数组 / 后缀自动机**：把字符串所有子串组织成可计数、比较或查询的结构。
- **凸包优化 / 李超树**：当 DP 转移能写成很多条直线在某个 x 的最小或最大值时，快速选择最优直线。
- **最大流 / 最小费用流**：在容量限制下运送尽可能多的量，或用最小费用送足指定流量；可建模匹配、路径与配额分配。
- **容斥**：先统计全部方案，再用交替加减去掉违反一个或多个条件的方案。

## 资料状态

这份合集的 400 指的是题目、中文条目和参考程序的覆盖数量，不是本次测试通过数量。

参考程序保留原作者版本。部分含 GNU 扩展（如 PBDS）、x86 相关优化或大量模板，不一定能在 macOS 自带编译器上直接编译。若你之后贴出某题的代码或错误信息，可以针对那一题核对与修正。

[解析订正清单](解析订正清单.md) 中的问题主要指原作者英文 AI 解析的题意、复杂度或证明，并不等价于这些题的参考代码都错误；其余解析也没有因此得到正确性认证。
