## 中文思路

**算法：**阶梯博弈

只异或奇数编号台阶上的石子数。偶数层移到奇数层的操作可由下一次奇数层向下移动抵消，奇数层构成有效 Nim 状态。

**时间复杂度：**O(n)。这里按上述解法说明；采用其他数据结构时复杂度可能不同。

**容易写错：**按题目的 1 基台阶编号判断奇偶。
