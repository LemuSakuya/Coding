## 中文思路

**算法：**单调栈与区间 DP

求每座山左右第一个高度≥自身的位置，范围内严格更矮的山可以作为下一站。按高度分组递增计算区间最大 dp，再统一写入线段树。

**时间复杂度：**O(n log n)。这里按上述解法说明；采用其他数据结构时复杂度可能不同。

**容易写错：**相等高度不能互相转移，也会阻断跨越；同高必须先查后改。
