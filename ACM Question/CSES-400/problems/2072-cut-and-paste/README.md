## 中文思路

**算法：**隐式 Treap

以子树大小作为位置，split 分离 [l,r] 片段，再把剩余两段合并，最后把片段接到末尾。

**时间复杂度：**期望 O((n+q)log n)。这里按上述解法说明；采用其他数据结构时复杂度可能不同。

**容易写错：**操作位置针对当前字符串，不能用初始下标。
