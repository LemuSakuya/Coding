**一、考试结构**
期末 60%，实验 30%，考勤 10%。题型大概是：单选、多选、填空、判断、简答、综合。
所以复习重点不是只背概念，还要会：**区分模型、写公式、解释流程、比较优缺点、做综合应用判断**。

**二、NLP总体框架**
自然语言处理 NLP，就是让计算机处理人类语言。核心任务按层次看：

```
词法分析 → 句法分析 → 语义分析 → 篇章分析
→ 语言模型 → 信息抽取 → 机器翻译 → 大模型
```

常见方法发展路线：

```
规则方法 → 统计机器学习 → 深度学习 → 预训练语言模型 → 大模型
```

基础任务要记：

- 词法分析：分词、词性标注、词形还原、词干提取
- 句法分析：成分句法、依存句法
- 语义分析：词义消歧、语义角色标注、语义表示
- 篇章分析：话语分割、指代消解、篇章结构
- 应用任务：命名实体识别、关系抽取、事件抽取、机器翻译

**三、词法分析**
中文分词很重要，因为中文没有天然空格。

常见分词方法：

- 正向最大匹配：从左到右，优先匹配最长词
- 逆向最大匹配：从右到左，优先匹配最长词
- 双向最大匹配：两边都切，再根据规则选结果
- HMM/CRF 分词：把分词看成序列标注
- BiLSTM/BERT 分词：用深度模型学习上下文

分词标注常用 BMES：

```
B：词首
M：词中
E：词尾
S：单字成词
```

词性标注 POS：给词标注名词、动词、形容词等。
词形还原 Lemmatization：还原到词典基本形式。
词干提取 Stemming：粗略去词缀，比如 playing → play。

评价指标重点：

\[ P=\frac{正确识别数}{系统识别数} \]\[ R=\frac{正确识别数}{标准答案数} \]\[ F_1=\frac{2PR}{P+R} \]

**四、句法分析**
句法分析看句子结构。

成分句法：把句子分成短语结构，如 NP、VP。
依存句法：看词与词之间的依赖关系，如主谓、动宾。

PCFG 是重点：概率上下文无关文法。
产生式形式：

\[ A \rightarrow \beta \]

每条规则带概率：

\[ P(A\rightarrow \beta) \]

一棵句法树的概率：

\[ P(T)=\prod_i P(r_i) \]

也就是把这棵树用到的所有规则概率乘起来。

**五、语义分析**
语义分析研究“这句话是什么意思”。

重点包括：

- 语义表示
- 词义消歧
- 语义角色标注

分布式表示是重点：
一个词的意义由它的上下文决定。Word2Vec、GloVe、BERT embedding 都属于这类思想。

词义消歧例子：

```
苹果很好吃 → 水果
苹果发布新手机 → 公司
```

语义角色标注 SRL：找谓词和论元。

```
小明 昨天 在学校 吃了 苹果
```

谓词：吃
施事：小明
时间：昨天
地点：学校
受事：苹果

**六、篇章分析**
篇章分析关注句子之间的关系。

重点概念：

- 篇章衔接：表面上有连接词、代词等
- 篇章连贯：语义上说得通
- 话语分割：把文章切成话题段
- 指代消解：判断“他、她、它、这”等指代谁

例子：

```
小明买了一本书，他很喜欢。
```

“他”指小明。

**七、语言模型**
语言模型用于计算一句话出现的概率。

\[ P(w_1,w_2,\cdots,w_n) \]

链式法则：

\[ P(w_1,\cdots,w_n)=\prod_i P(w_i|w_1,\cdots,w_{i-1}) \]

n-gram 使用马尔可夫假设，只看前面有限个词。

bigram：

\[ P(w_i|w_{i-1})=\frac{C(w_{i-1},w_i)}{C(w_{i-1})} \]

常见平滑方法：

- 加法平滑
- 古德-图灵估计
- Katz 平滑

困惑度 PPL：

\[ PPL=\exp(-\frac{1}{N}\sum_i \log P(w_i)) \]

PPL 越低，语言模型越好。

**八、BERT、GPT、BART**
BERT：

- Transformer Encoder
- 双向上下文
- 适合理解任务
- 预训练任务：MLM、NSP

GPT：

- Transformer Decoder
- 单向自回归
- 适合生成任务
- 目标：预测下一个 token

BART：

- Encoder-Decoder
- 去噪自编码
- 适合摘要、翻译、生成

BERT 输入组成一定要背：

\[ Input = Token Embedding + Segment Embedding + Position Embedding \]

特殊符号：

- `[CLS]`：分类用
- `[SEP]`：分隔句子
- `[MASK]`：遮盖词，用于 MLM

**九、Transformer重点**
Transformer 核心是自注意力机制。

\[ Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt{d_k}})V \]

Q、K、V 分别是 Query、Key、Value。
直观理解：每个词都去看句子里其他词，判断哪些词对自己更重要。

Encoder 适合理解，Decoder 适合生成，Encoder-Decoder 适合翻译。

**十、大模型与LoRA**
大模型训练流程：

```
预训练 → 指令微调 → 人类反馈强化学习 RLHF → 应用
```

参数高效微调 PEFT：冻结大模型大部分参数，只训练少量新增参数。

常见方法：

- Prompt Tuning
- Prefix Tuning
- Adapter
- LoRA

LoRA 一定重点背：

\[ W'=W+\Delta W \]

LoRA 不直接训练完整 \(\Delta W\)，而是低秩分解：

\[ \Delta W=BA \]

优点：参数少、显存低、训练快、适合大模型微调。

Flash Attention：优化注意力计算，减少显存读写，提高训练和推理效率。

**十一、信息抽取**
信息抽取是把非结构化文本变成结构化信息。

三大任务：

- 命名实体识别 NER
- 关系抽取
- 事件抽取

NER 识别人名、地名、机构名、时间等。

BIO 标注：

```
B-LOC：地点开头
I-LOC：地点内部
O：非实体
```

关系抽取例子：

```
乔布斯 创立 苹果公司
```

关系：创始人关系。

事件抽取包括：事件触发词、事件类型、事件论元。

**十二、机器翻译**
机器翻译重点有三条线：

```
规则翻译 → 统计机器翻译 → 神经机器翻译
```

统计机器翻译公式：

\[ \hat e=\arg\max_e P(e|f) \]

由贝叶斯公式变成：

\[ \hat e=\arg\max_e P(f|e)P(e) \]

其中 \(P(f|e)\) 是翻译模型，\(P(e)\) 是语言模型。

神经机器翻译：

- Seq2Seq
- RNN/LSTM
- Attention
- Transformer

机器翻译评价指标重点：BLEU。
BLEU 看机器译文和参考译文的 n-gram 重合程度，通常越高越好。

**十三、题型速记**
填空题重点背：NLP定义、分词方法、BMES、P/R/F1、n-gram、PPL、BERT输入、MLM/NSP、LoRA公式、BLEU。

判断题重点看：
BERT 是双向 Encoder；GPT 是单向 Decoder；PPL 越低越好；BLEU 越高通常越好；LoRA 不训练全部参数。

简答题模板：

```
先说明概念，再写核心流程，再写优缺点，最后举应用场景。
```

```

然后说明可用模型、输入输出、评价指标。
```
